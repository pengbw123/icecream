# 用户音色持久保存方案：优先 SD 卡（本轮为方案）

## 当前状态

- 原厂预设为 ROM1A/1B/2A/2B 共 128 个，只读默认音色。
- PATCH 页现有 8 个用户槽仍保存在软核 RAM，断电丢失；本轮没有实现 SD/Flash 保存驱动。
- 当前 RAM 槽包含名称、9 个全局字段、6×17 个算子字段、12 个 Pitch EG 字段；不包含 FX。
- 滑音是全局演奏方式，初始关闭，不作为原厂 DX7 音色字段。

## 硬件依据与选择

用户同意 SD 卡方案，建议优先使用板载 MicroSD，而将配置 Flash 保留为后续备选。

`06_硬件图纸/ACG720-138&60K通用原理图.pdf` 第 15 页有 J8 MicroSD_SOCKET；第 2 页连接到 FPGA：
SD_DATA3、SD_CMD、SD_CLK、SD_DATA0 可用于 SPI 模式的 CS、MOSI、SCK、MISO。
电路图标出 SD_CD，但 FPGA IO 页未列出此网，实施前核对实板；不能假定插卡检测脚已可用。
第一版可用初始化和读写超时判断卡是否在线。电气实现以完整原理图和实际卡座为准。

同份原理图第 2 页 U3 为 MX25L12845G，128 Mbit（16 MiB）QSPI Flash，SCK 接 FPGA 配置时钟引脚。
Flash 与启动配置共存，需要确认运行时访问方法及配置区布局。SD 卡方便电脑备份，也适合后续 MIDI 曲库。
不需要 DDR 或更换软核。

## 用户功能

- FACTORY 128 个：载入、查看、编辑后另存 USER，禁止覆盖原厂表。
- USER 128 个逻辑槽：命名、保存、载入、覆盖确认、删除；分页浏览。
- 编辑发生在 RAM，明确按 SAVE 才写卡，不随滑条自动写入。
- 音色与 FX 一起保存；载入时提供是否恢复 FX 的选项。
- 主音量、耳机/音响选择、主题等属于系统设置，独立保存，避免换音色导致输出音量跳变。
- 未插卡时可继续使用原厂音色和临时编辑；保存入口清楚提示 NO CARD，不把 RAM 保存冒充持久保存。
- 写入期间显示 SAVING，完成校验后显示 SAVED；读取错误不覆盖当前正在使用的 RAM 音色。

## 建议目录与格式

```text
/FM/USER/U001A.FMP       用户槽 001 的 A 副本
/FM/USER/U001B.FMP       用户槽 001 的 B 副本
/FM/USER/...            至用户槽 128
/FM/SYSTEM.CFG          独立系统设置
/SONGS/                 后续 MIDI / 编译曲目文件
```

第一版支持 FAT32、8.3 文件名，暂不加入 exFAT、长文件名或中文文件名，以控制代码和 RAM 占用。
屏幕内的音色名称存在文件内容中，不依赖文件名。可由电脑直接备份这些文件。
原厂 128 个音色仍在 FPGA ROM 中，不要求插卡才能开机或发声。

每条 FMP 记录建议固定 512 字节，显式小端序列化，禁止直接写 C 结构体内存：

`magic | 格式版本 | 槽编号 | 有效长度 | 序号 | 名称 | FM 参数 | FX 参数 | CRC32`

原生快照用于无损恢复当前可编辑参数；另可提供可表达字段的 DX7 `.syx` 导入导出。
自定义路由、编译后的包络和 FX 不强行塞入 DX7 标准音色格式。

## 保存与掉电处理

每个槽保留 A/B 两个副本：保存时更新较旧副本，写完同步并读回校验；加载时选择 CRC 正确且序号最新的副本。
不先删除上一份有效记录。目录只缓存名称、有效位和位置等信息，完整音色按需读取，节省软核 RAM。

A/B 与 CRC 能减少单个音色半写造成的损失，但 FAT32 本身不提供掉电事务，不能承诺任意拔卡/断电都不会损坏文件系统。
界面在写入时提示等待完成，保留电脑备份；验收必须覆盖保存中断电、坏卡、卡满、拔卡和 CRC 损坏。

## RTL / 软核分工与资源

- RTL SPI 控制器负责字节移位、时钟及有界超时，通过寄存器/FIFO 提供扇区读写接口。
- 软核负责精简 FAT32 文件访问、目录、快照校验和菜单状态。文件读写不能阻塞音频 RTL 流水。
- 初始化先用低速，正常访问再提高到足够的 SPI 速度；音色仅几百字节，不需要四位 SDIO 的复杂度。
- 当前固件约 42 KiB，代码窗口 64 KiB；文件系统需裁剪后实测尺寸，不能默认完整功能库能放下。
- 先支持有限的打开文件数和一个 512 字节扇区缓存，再按实际栈/RAM 测量决定是否增加缓存。
- 后续 MIDI 曲库可共用 SD 驱动，先读取电脑预处理曲目格式，再逐步增加原始 SMF 解析。

## 实施顺序

1. 核对卡座管脚/CST，与 RGB、HDMI、音频等现用 IO 排除冲突。
2. 实现 SD SPI 初始化及只读扇区验证，使用测试卡完成扇区写入/读回。
3. 接入精简 FAT32，测量程序 ROM、RAM 和最坏读写延迟。
4. 实现原生快照、A/B 副本、CRC、启动目录扫描与错误处理。
5. 扩展 PATCH 的 FACTORY / USER 界面，提供保存结果和无卡提示。
6. 实机比较恢复前后的全部 FM/FX 字段与发声结果，测试播放时保存、卡满、拔卡和保存中断电。

## Flash 备选

如果后续要求无卡也能保存，可在配置 Flash 的已确认空闲区域另设用户分区。
必须先读 JEDEC ID 并确认配置二进制占用和下载器擦写布局，不能依据 `.fs` 文本文件大小决定地址。
硬件写控制器限制范围；采用日志追加、CRC、提交标记和双区回收。
烧录新 FPGA 固件的流程也必须保留用户分区，整片擦除会连同用户数据一起删除。
