# 数字链路延迟与示波器端到端测量

本模块不是“按键到耳朵”全链路自动测量。起点：LIVE NoteOn第一次出现在top.v数字入口仲裁输出，尚未进入内部弹性缓存，包含该点之后的等待；不含CH376/USB包解析与上游FIFO、物理键盘/触屏扫描。终点：最终音频超过32LSB后的第一帧I2S左声道字，其最后一位的采样上升沿。包括合成、效果、主音量、帧等待和左声道串行发送；不包含DAC和模拟滤波。不是给每个并发音符添加时间标签的因果跟踪器。

SETUP→METERS：NOTE>I2S us NOW/MAX显示整数微秒最近/最大值；ONSET OK/TIMEOUT为成功和超时/模式中断数；ONSET SKIPPED是未满足条件的新NoteOn数量。原READY（音频tick到计算完成）和采样周期行被替换，旧MMIO0..17布局保留，新增18..23为最近时钟数、最大时钟数、成功数、超时数、跳过数、状态。CLEAR同时清理两组统计；清理中的测量取消。状态bit0等待起音、bit1已锁存候选帧、bit2安静资格、bit3测量允许。

资格：连续32帧绝对值≤32且活跃声部为0；关闭ARP、SEQ、AI伴奏、AI旋律和练习模式。只弹一个LIVE音符，等待充分静音后再弹。连奏、和弦不作为可归属单音测量；等待期间再来NoteOn会取消当前测量。250ms未出现合格起音记超时。静音、低音量、慢起音会影响结果，数字值不得冒充纯算法耗时。

示波器：原status_led[0]心跳改为测量标记，对应CST中的FPGA管脚M22。用板上对应LED线路的FPGA侧测试点/串联电阻焊盘取信号，先对照本板原理图确认位置，不要直接触碰BGA球。CH1探测标记，地夹接板GND，以上升沿单次触发；标记从数字事件出现后拉高，直到I2S完成、超时或取消。它不再是心跳灯，其他7个状态灯功能不变。

CH2建议取ES8388耳机输出的一路模拟信号，使用3.5mm转接板，选择SETUP的HEADPHONE输出，耳机先拔下，示波器输入高阻。两通道共板GND。不要将普通接地探头的地夹接MAX98357的SPK-：那是桥接功放输出，不是地；测扬声器端须用合适的差分方法。本方案优先测耳机口。

设置快速起音、固定音色和力度、关闭全部效果，先调到波形清楚且无削顶。测CH1上升沿到CH2持续越过静音噪声门槛的时间，保存原始波形；写明起音阈值、输出口、音量、音符和负载。这个结果是“FPGA数字入口到模拟起音”；若要测真正物理按键到模拟输出，还需CH1改接键盘/传感器侧参考信号，或增加通道同时测两个起点。触屏首次接触无法从现有NoteOn标记倒推出扫描时间。

每种来源建议重复至少30次，记录最小/中位/最大值；再在高复音、显示与摄像头同时运行时测。测带效果/慢包络的听觉起音时，要另列其有意延时，不能和干声引擎延迟混报。本轮没有预先填写任何实测数值。

现场多频测试模式建议：选择ALGO32（六算子均为载波），仅开启一个正弦算子，反馈0、关闭LFO/滑音和所有效果，快速起音、稳定保持包络。依次保持4/8/16/32个不同MIDI音符，停止时释放全部音符；这可以先由PC/键盘发送MIDI和弦，音频仍全部由FPGA实时生成，不是播放录音。建议4音C4/E4/G4/C5，32音MIDI48..79。频谱分析采用足够长的FFT（如32768点）和适当窗函数，频率轴按采集设备实际采样率标定。当前屏幕的频段柱状图不适合精确清点32条窄谱线，可使用外部音频采集后的高分辨率频谱。

演示时同时显示活跃声部数、deadline/lost_ticks/drop计数和频谱：加一个音应多一个基频峰，释放后对应峰消失；不能把单个FM音色的谐波峰算成多个独立声部。32条正弦只能证明32个独立可闻声部，不能据此证明192个可闻算子。正式的板载一键多频模式尚未加入，本说明给出其具体规范和可立即使用的外部MIDI验证路径。

代码验证：精确I2S最后位终点、输入VALID背压去重、安静门限、超时、重叠音符取消、清理和快照已有专项仿真；I2S输出选择及真实AI/FM32/I2S回归通过。完整构建及当前下载状态以发布记录为准，尚未实机测量。
