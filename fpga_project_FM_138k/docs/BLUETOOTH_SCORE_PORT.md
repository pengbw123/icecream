# 蓝牙、灯带与曲谱移植（2026-10-31）

来源：用户指定的 https://github.com/tlemon229/Gowin-Instrument-138K.git ，分支 `codex/instrument-138k`，提交 `7bc0f80a8fd6eb9835cd11b5081097794c8b2048`。移植独立 JDY 串口、灯位校准、《晴天》灯带指引/等键练习、MIDI 曲谱上传回放及配套 Android 源码。保留本工程的 CH376、32 复音、双 Part、RGB 菜单、摄像头灰度识别、AI 和延迟测量。不能用队友的早期顶层替换本工程。

## 接线与使用

* JDY 模块 TX → P7-9 / FPGA E13（bluetooth_rx_pin）；JDY RX → P7-10 / FPGA E14（bluetooth_tx_pin）。共地，UART 为 3.3V 逻辑，115200 8N1。模块电源按所用 JDY 小板规格连接；不要给 FPGA IO 输入 5V。
* 灯带沿用现有 ws2812_data 输出，160 颗上限。灯带供电沿用实机方案；FPGA 只输出 DIN 控制。
* S0（F15）开始内置灯带练习；S1（A20）停止练习或自动演奏。保留 S4 复位及现有 LED0 延迟测量标记。
* 手机选择“138K《晴天》灯带指引”，连接 JDY 后先检测接口。设置灯带数量，完成 25 键灯位校准并“写入 FPGA”；默认 ROM 灯位为空，不含个人灯位。校准保存在手机，板复位后重新写入。
* 内置曲目提供固定速度跟弹、预备拍、移调，以及“弹对再走”。重复同音需要松开再按。USB、桥接及屏幕键盘按各自来源追踪，曲谱自动演奏不会被当成人工答题。
* 手机导入 MIDI，检测能力→上传→CRC 封存成功→手动播放。最多 8192 个音符事件（NoteOn/NoteOff 各算一个），32 复音上限与手弹共用。上传后可断开蓝牙继续播放；RAM 曲谱断电/复位丢失。
* 当前按主音色演奏，整体音量/音色仍在 RGB 菜单控制。不是 MIDI 多轨各自音色播放器，也没有把手机的旧加法合成音色协议接进 FM 参数口。

## 与现有模式的协调

蓝牙练习/曲谱回放与 ARP、音序、AI 伴奏、AI 旋律、原屏幕辅助演奏互斥。启用这些模式会停止蓝牙演奏；模式占用时拒绝新的蓝牙播放请求，但允许上传、探测、停止与灯位配置。硬件停止没有主动手机状态推送，手机操作前可停止/重新探测以同步状态。

曲谱播放和收尾期间临时屏蔽 LIVE 单音滑音，保留用户设定，结束后恢复。自动事件使用内部 0x88 标签，绕过人工输入的琶音/录制路径；STOP 的 CC64/CC123 仅清理 LIVE Part，避免误杀 BACKING。手动全局 panic 仍为全局。曲谱 STOP 同时释放同一 LIVE Part 的手弹音，暂未增加第三个独立音色/所有权域。

## 资源与协议

8192×48bit 缓存按 `{velocity8,note8,delay_ms32}` 存储。F1 能力返回 8192 事件、32 复音；兼容最多 8 事件一组的上传及逐帧回退，最终数量和 CRC32 必须正确。未实现的 reliable-v2 明确拒绝，不宣称支持。蓝牙独占串口与 CH340 的 FM 控制口分离。

UI 数据地址窗口仍为 96KiB，但物理 DATA RAM 只保留低 16KiB BSS 及高 32KiB 常量/栈，去掉中间 48KiB 空洞，理论节省 24 个 BSRAM。指令 ROM 保留 80KiB。布局脚本和链接脚本约束 BSS≤16KiB、常量≥64KiB、栈余量≥12KiB；未来菜单扩展必须重新检查。没有删除功能或降低音频/摄像头缓存规格。实际资源及所有时钟 setup/hold 以本次构建报告为准。

## 源码、验证与交付界限

RTL 在 `src/led_guide`、`src/score` 和三个 UART 模块中，板级连接在 `src/top_138k_hdmi.v`。仓库根目录 `android_control`、`pc_control`、`scores` 是配套源码/测试素材；Android README 下方为上游历史记录，旧 FS、工具路径和验收结论不适用于本工程本次构建。未复制 APK、签名私钥或本机 SDK；没有自动烧板、安装手机或推送 Git。

验证包含事件容量边界、Android 实际生成字节→UART→RTL CRC/回放、STOP 背压、模式互斥、32 复音能力、FM 分 Part 清理及稀疏 RAM 边界。Java reliable-v2 测试只验证 App 模型，不能作为板端支持证据。手机蓝牙吞吐、实际灯位、声音及板上兼容性仍需实机验收。最终位流仅在完整布局布线且所有约束时钟通过后替换；旧版保留回滚。
