# 16 步音序器第一版

## 功能和操作

入口为 **SETUP → STEP SEQUENCER >**（右上方），内部页面 11。
保留底部 800×128 全宽琴键。离开音序器页面可以继续播放，返回该页按 STOP 停止。

- 8 组独立 RAM 模式，每组最多 16 步，长度可设 1～16；每步单音，保留独立力度。
- 模式 1 默认是上行/下行 C 大调音阶示例，模式 2～8 默认为休止。
- **START / STOP**：每次开始从该组第 1 步播放，连续循环；STOP 释放音序器自己的音。
- **STEP REC**：停止自动播放，进入步进录入。外部 MIDI 或触屏的每个新非零力度 Note On
  写入当前选中步骤，随后游标前进，到所设长度后回第 1 步。Note Off 不前进。
  和弦的多个 Note On 会依次写到多个步骤；本版不做实时量化录音或逐步和弦。
- **REST**：写一个休止步；录入开启时自动前进一步。
- **TIE**：延长前一个音，不重新触发包络。前一步 NOTE 后接 TIE 时，跨越完整的连音步骤；
  连音链最后一步结束才松键。没有前音时 TIE 保持静音。
- 点网格选择步骤，下面的 NOTE / VELOCITY ± 修改该步，可按住重复调节。
  修改音高或力度会把休止/连音改为普通音符，默认从 C4、力度 96 开始。
- 网格中 `>` 标记播放位置，选中底色标记编辑步骤；`x` 表示超出当前模式长度、暂不播放。
  超出长度的存储步骤仍可编辑，后续增加长度后会重新参与播放。
- PATTERN ± 切换组。播放中换组在下一个步骤边界进入新组第 1 步；修改步骤用于后续读取。
- **CLEAR BANK** 需要再点一次 **CONFIRM?** 才清空当前组，其他组不变。
- SETTINGS 切换参数视图，STEPS 返回网格。BPM 与琶音器共用，范围 30～240。
  RATE 为 1/4、1/8、1/16、1/32、1/8 T、1/16 T，默认 1/16；
  GATE 10%～95%，默认 70%；SWING 50%～75%，默认 50%。相邻两步总时长不变。

录入保留已经过输入校准的 MIDI 力度（1～127）；自动播放使用当前音色、FX 与统一主音量。
模式只保存音符与力度，不保存音色、CC、弯音、踏板或原始录入时间。
8 组均是易失性 RAM，复位重新生成默认模式，掉电不保存。本版没有 SD 或 USB/蓝牙通信驱动。

## 与现有功能

- 开始播放或录入会退出 ARP，临时关闭 GLIDE MONO；停止后恢复原滑音模式。
- 主动开启 ARP 或 GLIDE MONO 会先停止音序器。
- FM 内核踏板延音为全局状态。开始播放/录入先释放踏板，期间踏板 CC64 按关闭传给内核，
  保证 GATE 和 TIE 不被全局延音覆盖；普通演奏恢复正常踏板功能，需重新踩下，不恢复旧踏板值。
- 进入 PRACTICE 会先停止音序器，硬件也有独立 suspend 保护，退出后不自动重启旧循环。
- 播放时仍可用外部键盘/触屏演奏；音序器和手动的同音通过已有所有权队列共享发声，
  一方的 Note Off 不会释放另一方仍持有的音。
- 音序器只发自己拥有音符的 Note Off，不用 CC123 清空用户手动声音。
  收到外部 CC120/123 会停止音序器和步进录入；菜单状态随后同步。
- 恢复单音滑音时，已有 FM 模式切换会清理声部分配，这与当前单音/复音切换规则一致。

## RTL 实现

`src/step_sequencer.v` 在 UI 控制器中独立执行，软核只设置参数和绘制字符。
播放采用 50 MHz 域的微秒时基；屏幕刷新和 I2C 轮询不控制节拍。
参数影子时长在控制写入时原子提交，当前步骤不被截断。
输出 MIDI 使用 ready/valid，停顿时保持事件不变，必须排完 Note Off 才结束清理。
调度与事件排队有微秒级开销；阻塞时冻结计时，不保证外部拥塞下仍绝对跟随墙钟。

128×32 位模式存储有同步读取：当前步、下一步和 UI 查询。
下一步用于判断 NOTE 是否应该因 TIE 而延长；录音游标和 UI 查询地址独立，
刷新 16 步显示不会改变录入位置。复位后的 128 个时钟逐项初始化模式 RAM。

内部生成事件沿用 bit31 的示范所有权。辅助演奏与音序器互斥，避免共用同一所有者同时发声。
UI MIDI 合流优先级为固件手动事件、练习示范、音序器，随后进入统一入口与 ARP/所有权队列。
音序器播放/录入/清理期间暂停 ARP。原始输入监视用于录入，忽略 bit31 的自动演奏事件。

## 后续存储/下载接口

总线基址 `0x23000000`，以下为 32 位字索引。

| 索引 | 读写含义 |
| --- | --- |
| 46 | 控制写入并原子提交 50～53 时长，读为最后控制值 |
| 47 | 读写编辑/录音游标，低 7 位地址 = 模式×16 + 步骤 |
| 48 | 写当前编辑地址的步骤；读 UI 查询地址的步骤（两种地址独立） |
| 49 | 只读状态 |
| 50 / 51 | 偶数 / 奇数步骤时长，微秒，影子寄存器 |
| 52 / 53 | 偶数 / 奇数步骤音长，微秒，影子寄存器 |
| 54 | 写 bit0=1 清空编辑游标所在组，需要先关闭录入 |
| 55 | 读写 UI 查询地址，不改变编辑/录入游标 |

控制：bit0 RUN、bit1 RECORD（与 RUN 互斥，优先录入）、bit2 重来翻转位，
[5:3] 模式 0～7、[9:6] 长度减 1。

状态：bit0 运行、bit1 录入、bit2 初始化/清空/清理或待发送事件、bit3 活动音、bit4 写入错误；
[11:8] 播放步骤、[18:12] 编辑游标、[23:19] 当前播放长度、[26:24] 当前播放组。
停止时播放组可保留上次值，选中组应读写控制寄存器及编辑地址。

步骤格式 v1：

```text
bit31 NOTE（优先）；bit30 TIE（仅 bit31=0 时生效）；二者均 0 为 REST
[14:8] velocity 1..127；[6:0] MIDI pitch 0..127；其他位保留为 0
```

NOTE 的力度 0 视为休止。手动写入在录入开启时拒绝并置错误位，避免和硬件录入争抢单写端口。
固件写 REST/TIE 或改音符时，会短暂关闭录入，完成写入再恢复。查询不受该限制。
装载方应停播放/录入、等待状态 bit2 清零，再逐项写入；不需要参与播放节拍。
未来 SD、USB、蓝牙适配可以复用这个步骤格式和寄存器入口，再增加文件格式版本、校验和掉电保存。

- `tb_step_sequencer`：默认模式、分组隔离、循环、NOTE/REST/TIE、音长、力度、全音域、
  步进录入与回绕、录入写冲突拒绝、播放中换组、输出停顿、STOP、练习暂停和清空。

  REST/TIE、音高/力度、跨页运行、BPM/RATE/GATE/SWING、二次确认清空。
