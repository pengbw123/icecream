# AI 伴奏是怎么做出来的

## 在哪里训练

在开发这份工程的 Windows 电脑上训练，用电脑的 CPU 跑 Python 和 NumPy。
没有调用云端训练服务，没有使用 GPU，也没有让板上的软核运行训练。
工程根目录：`D:\a_My_projects\Gowin_publish\fpga_project_FM_138k`。

训练日志保存为 `assets/ai/ai_bass_training.log`，下载的数据在 `tmp/ai_pop909/POP909`。
tmp 是本机临时目录，不提交 Git；换一台电脑需要重新下载数据。
源码、训练结果、权重和数据来源清单均在工程内，已纳入 Git。

## 一句话理解

先用已有乐谱教一个小网络“在这种演奏和拍点下，低音下一步通常怎么走”，
再把学到的数字装进 FPGA，让 FPGA 边接收你的 MIDI 边作选择。
训练是电脑上的准备工作；实际演奏时，板子独立运行，不需要连接训练电脑。

## 从乐谱到板子的六个步骤

1. **取学习材料。** 下载 POP909 的前 48 首候选 MIDI 及节拍、和弦标注。
   其中 47 首满足本版 4/4 处理条件。这里的 MIDI 是音符和时间信息，不是录音。
2. **整理问题和答案。** 每个十六分音符拍点形成一道练习题。
   问题包括：当前拍点、已发生的旋律音、最近的起音、当前给定和弦等。
   答案从 PIANO 伴奏轨的低声部简化得到，不是人工标注的独立贝斯轨。
3. **让小网络练习。** 使用 48→32→8 的两层网络。48 是输入信息项数，
   32 是中间计算节点数，8 是可选的伴奏动作数，不是 32/48 路音频。
   输出动作是休止、保持、根音、三音、五音、高八度、低五音和半音连接。
   算错时，训练程序微调内部数字；共训练 45 轮，固定随机种子 138。
4. **用没学过的歌检查。** 按整首歌划分：31 首训练、8 首验证、8 首测试，
   避免把同一首歌拆开混入训练和考试。训练集 72,634 条，验证集 18,168 条，
   测试集 18,712 条。用验证集挑选模型，最后报告测试集结果。
5. **把数字变成适合 FPGA 的格式。** 1,792 个权重转成 INT8，另有 40 个偏置。
   导出 `.mem` 文本，随 RTL 一起综合进 FPGA。
6. **实时演奏。** RTL 整理最近的 MIDI 信息，读取权重做整数乘加，选一个动作，
   再转成 MIDI 音符交给现有 FM 引擎发声。推理本身固定 3,664 个 50 MHz 时钟，
   即 73.28 微秒；节拍等待、输入整理和音频输出时间另算。

## 举一个实际例子

在 AI BASS 页面选 C 调、I-vi-IV-V、120 BPM，先选择贝斯音色并 START。
和弦按每小节 C 大三和弦→A 小三和弦→F 大三和弦→G 大三和弦循环。
你可以切换 LIVE 为电钢琴继续弹，低音声部使用启动时保存的音色。

在 C 和弦期间，如果网络选择“根音”，调度器发 C；选择“五音”则发 G；
选择“保持”就延长前一个音；选择“休止”就释放低音。
网络会接收你最近弹奏的信息，但不保证你每次按键都会立即触发一个低音。
本版在十六分音符时钟上生成动作；相同输入和状态会得到相同结果。

网络负责从八个动作中选择；节拍推进、预设和弦循环、稀疏模式限制、NoteOff、
暂停和防止卡音由常规 RTL 负责。这些规则和训练模型共同组成现在的伴奏系统。

## 怎样重新训练

在工程根目录打开 PowerShell。Python 环境需要 NumPy 和 mido：

```powershell
python -m pip install numpy mido
python tools/ai_accompaniment/fetch_pop909.py --songs 48
python tools/ai_accompaniment/train.py --epochs 45
```

训练会覆盖 `src/generated/ai_bass/` 中的权重、报告及参考测试向量。
重新训练以后，要重新进行 RTL 仿真、Gowin 综合布局布线和烧录，板子才会使用新模型。
只运行 Python 不会自动改变已经烧录的 FPGA。

## 当前水平该怎么理解

测试集动作准确率约 83.29%，但数据里“保持”很多：全部猜“保持”也有 79.61%。
各动作平均召回率约 34.12%，说明小众动作仍弱，不能用 83% 宣称伴奏已经专业。
这些成绩只检查动作标签，不等于人耳觉得好听，也不保证长期自生成时的听感。

现在是小样本、单轨低音、给定和声的流行伴奏原型。不是大语言模型，
不会理解你任意弹出的和弦，不会生成完整鼓组和多乐器编曲，也没有现场继续训练。
下一步应先实机听不同旋律和和弦的效果，再决定扩大数据、改特征或换更强的网络。
