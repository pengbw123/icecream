# FM 合成器触摸屏使用说明（零基础版）

这台机器是一台 6 算子 FM 合成器 + 800×480 触摸屏。下面假设你完全没接触过 FM 合成，
按"屏幕怎么用 → 每个页面是干什么的 → 每个参数什么意思"的顺序讲。

## 0. 先认识三个词

- **算子（Operator）**：机器里有 6 个"发声单元"，每个算子会发出一个正弦波。编号 OP1～OP6。
- **算法（Algorithm）**：决定这 6 个正弦波谁调制谁、谁直接出声。共 32 种连线方式。
- **包络（Envelope / EG）**：一个音从按下到松开，音量（或音高）会随时间变化，这条"变化曲线"叫包络。

FM 的声音 = 用一些算子去"调制"另一些算子的频率，再叠加输出。所以同一个音色里，
调制量、每个算子的音量、包络快慢，都会明显改变音色。

## 1. 屏幕布局

```
┌──────────────────────────────────────────────┐
│ 1 PERF │ 2 ALGO │ 3 OSC │ 4 EG │ 5 LFO │... │  ← 顶部页签，随时可点
├──────────────────────────────────────────────┤
│  状态行：P01 音色名  V096  O+0  A05  3V       │
│                                              │
│              当前页面的内容                    │
│                                              │
└──────────────────────────────────────────────┘
```

- 顶部 8 个页签就是 8 个页面，**点哪个就去哪个页面**，演奏页也一直保留页签。
- 第 2 行是状态行：`P01` 当前音色号、音色名、`V096` 主音量、`O+0` 八度、`A05` 算法号、`3V` 正在发声的声部数。
- 页面里**点一行 = 选中**（橙色高亮），后面对应这一行的 `-` / `+` 按钮改值。

### 通用操作

| 操作 | 效果 |
|---|---|
| 点页签 | 切换页面 |
| 点某一行 | 选中该行 |
| 点 `-` / `+` | 单步改值（点一下动一格） |
| 按住 `-` / `+` 约 1.5 秒 | 开始连续改，松开停止 |
| 在选中行上左右拖动 | 快速连续改（滑条） |
| 点 `1 PERF` | 回演奏页 |

> 注意：参数改完只存在机器内存里。切到别的音色会重新载入那个音色的原始参数，你的修改会丢；
> 关机也会丢。想留住就存到"用户槽"（见 7 NAME 页）。

## 2. 演奏页（1 PERF）

![演奏页](../tmp/perf_composite.png)

- **左边大框**：波形示波器（WAVE）或李萨如（XY），用 `VIEW` 按钮切换。
- **中间竖条**：当前输出电平，越高越响，顶到红色表示削波（声音可能破）。
- **下面 6 根柱子**：6 个算子当前的包络电平，能直接看到哪些算子在发声。
- **底部键盘**：25 键，点/滑可以弹奏。
- **右侧快捷键**：
  - `PRESET`：换音色（32 个内置音色）。
  - `VOLUME`：主音量。
  - `OCTAVE`：键盘八度（-3～+3）。
  - `PANIC`：所有音立刻关掉（卡音时用）。
  - `VIEW`：波形/李萨如切换。
  - `XY DELAY`：李萨如的余辉/延迟长度。
  - `AUTO`：示波器自动增益（安静时也能看清波形）。

## 3. 算法页（2 ALGO）

- `ALGORITHM`：算法编号 1～32，换算法 = 换 6 个算子的连线方式。
- `FEEDBACK`：反馈量 0～7。某个算子用自己的输出调制自己，越大越"粗糙/金属"。
- `OSC SYNC`：算子同步开关。打开后音高变化时波形会"硬同步"，声音更有冲击力。
- `TRANSPOSE`：整体移调 0～48（半音）。
- 下面的**路由图**：6 个方框，每个算子一框，显示三件事：
  - `OUT`：这个算子的声音去了哪里。`CAR` = 直接进输出（载波）；`BUS1/BUS2` = 去调制别的算子。
  - `IN`：谁在调制它。`--` = 没有；`BUS1/BUS2` = 被对应总线的算子调制。
  - `FB`：这个算子有反馈。
  这张图是 FPGA 里真实的连线状态，换算法会实时变化。

## 4. 算子页（3 OSC）

先点顶部 `OP1`～`OP6` 选择要编辑的算子，然后：

| 参数 | 通俗解释 |
|---|---|
| `MODE` | `RATIO` 频率是基准音的整数/半整数倍；`FIXED` 用固定频率（做噪音、金属声常用）。 |
| `COARSE` / `FREQ` | RATIO 模式下的倍数（0.5、1、2、3…）；FIXED 模式下是固定频率档。 |
| `FINE` | 微调（0～99），让两个算子稍微"跑调"，声音更厚。 |
| `DETUNE` | 细微失谐（-7～+7），多个算子叠加时产生合唱感。 |
| `LEVEL` | 这个算子的输出音量（0～99）。 |
| `RATE SCALE` | 高音区包络是否变快（0～7）。 |
| `VEL SENS` | 力度灵敏度：弹得越重，这个算子越响（0～7）。 |
| `AM SENS` | LFO 对音量的调制深度（0～3）。 |
| `KEY BP` | 键位缩放断点：以哪个键为"中心"（0～99，约等于音高位置）。 |
| `L DEPTH` / `R DEPTH` | 断点左边/右边的音量衰减量。 |
| `L CURVE` / `R CURVE` | 左边/右边衰减曲线的形状（-LIN/-EXP/+EXP/+LIN）。 |
| `ENABLE` | 这个算子开/关。关掉相当于把它从音色里拿走。 |

## 5. 包络页（4 EG）

这是最影响"手感"的页面。先把 `AMP EG` / `PITCH EG` 看清楚：

- **AMP EG（音量包络）**：控制这个算子从按下到松开的**音量**变化。
- **PITCH EG（音高包络）**：控制整个音从按下到松开的**音高**变化（做打击乐"咚"、铜管"哇"常用）。

先点 `OP1`～`OP6` 选算子，再编辑：

| 参数 | 通俗解释 |
|---|---|
| `RATE 1..4` | 第 1～4 段的变化**速度**，越大越快（0～99）。 |
| `LEVEL 1..4` | 第 1～4 段结束时要到达的**音量**（0～99）。 |

想象按下琴键后，音量按 4 段走：

```
按下              按住               松开
 |---R1--->|--R2-->|----R3----|      |--R4--> 0
 从 0 到 L1  到 L2    到 L3(持续)        到 L4
```

- `R1` 是"起音"速度（attack），越大越"啪"。
- `L1` 通常是最大音量。
- `R2` 是"衰减"速度，`L2` 是衰减到的位置。
- `R3/L3` 是按住时的"延音"（sustain）。
- `R4/L4` 是松开后的"释放"（release），L4 通常设 0。

**右边的柱状图**就是这 4 段的目标音量画成的 4 根柱子：柱越高 = 这一段结束时越响。
它只是"形状预览"，帮你快速判断包络是"快起慢落"还是"慢起"。

PITCH EG 模式里：
- `PRATE 1..4` 是四段音高变化速度。
- `TARGET 1..4` 是四段的目标音高，`50` = 原音高，小于 50 往下滑，大于 50 往上滑。

## 6. LFO 页（5 LFO）

LFO 是一个"自动来回摆"的低频振荡器，用来做颤音、哇音。

| 参数 | 通俗解释 |
|---|---|
| `WAVE` | LFO 波形：三角/锯齿/方波/正弦/采样保持。 |
| `SPEED` | 摆动速度（0～99）。 |
| `DELAY` | 按下后过多久 LFO 才开始（0～99），做"延迟颤音"。 |
| `P MOD DEPTH` | 音高抖动深度（颤音）。 |
| `A MOD DEPTH` | 音量抖动深度（ tremolo）。 |
| `P MOD SENS` | 全局音高调制灵敏度（0～7）。 |
| `LFO SYNC` | LFO 是否跟随按键重新开始。 |
| `KEY SYNC` | 每个音是否从波形起点开始（0 相位）。 |

## 7. 名字/用户槽页（7 NAME）

- 上排 10 个字符是当前音色名。
- 点某个字符 → 选中；用右边的 `-` / `+` 换字符（A-Z、0-9、`-`、`.`、空格）。
- `SLOT -` / `SLOT +`：选择 8 个用户槽之一。
- `SAVE`：把**当前全部参数**（全局 + 6 个算子 + Pitch EG）存进当前槽。
- `LOAD`：把槽里的参数读回来。
- 槽里的数据在内存里，**关机也会丢**；但切音色不会丢（切回来 LOAD 一下即可）。

## 8. 主题页（8 UTIL）

点一下屏幕切换配色：`GRAPHITE`（红）/ `AMBER`（琥珀）/ `ICE`（青）。
主题会同时改变界面、波形、李萨如、电平条、包络柱和键盘的颜色。

## 9. 常见问题

- **没声音**：看 `PANIC` 后重新弹；检查 `VOLUME`；检查当前音色的算法里是否有载波（全部算子都去调制别人时可能没输出）。
- **声音破**：电平条顶到红，降低 `VOLUME` 或算子 `LEVEL`。
- **按键一直响**：点 `PANIC`。
- **改完参数换音色就没了**：正常，先 `SAVE` 到用户槽再换音色。
- **按 `-`/`+` 没反应**：确认那一行是橙色选中状态；按住 1.5 秒才开始连发。
- **菜单里参数显示和 PC 编辑器差 1**：EG 的 0～99 与内部定点换算取整导致，声音是对的。
