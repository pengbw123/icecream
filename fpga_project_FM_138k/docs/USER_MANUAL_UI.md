# FM 合成器触摸屏使用说明（零基础版）

## 2026-10-24 USB 键盘接入

新版使用外接 CH376S 模块的 USB-A 接键盘，SPI 接 138K，不再需要 25K 中转。
原触屏菜单与32复音保持；模块模式/接线/状态灯见 [USB 接入说明](CH376_USB_MIDI.md)。
此功能尚待用户实机验证，不能把键盘直接插板上 USB 设备口代替 CH376S。

## 2026-10-24 32 复音版

标题声部容量更新为 32，性能页同样显示 32。踏板保持和松键尾音也占用声部；
满载后继续起音会抢占旧声部，VOICE STEALS 增长属于正常现象。
滑音开启时仍为单音连奏，关闭后恢复 32 复音。详见 [32 复音说明](POLYPHONY_32.md)。

## 2026-10-24 性能监测

在 **SETUP → PERFORMANCE >** 打开性能页，连接 MIDI 键盘照常演奏即可查看。
左列显示复音、FM 计算/结果就绪耗时、引擎忙占比和采样周期；右列显示超时、丢采样、抢音、
桥接丢事件和 MIDI 等待情况。正常演奏中，DEADLINE MISSES、LOST SAMPLE TICKS、BRIDGE DROPS 应为 0。
FREEZE METRICS 冻结数值供查看，RESUME METRICS 恢复刷新；CLEAR COUNTERS 清零计数与峰值，均不停止声音。
时间只测量 FM 数字引擎，不代表按下键盘到耳机的完整延迟。详见 [性能监测说明](PERFORMANCE_MONITOR.md)。

这台机器是一台 6 算子 FM 合成器 + 800×480 触摸屏。下面按"屏幕怎么用 → 每个页面干什么 →
每个参数什么意思"讲，不需要 FM 基础。

## 0. 先认识三个词

- **算子（Operator）**：机器里有 6 个"发声单元"，每个发出一个正弦波，编号 OP1～OP6。
- **算法（Algorithm）**：决定这 6 个正弦波谁调制谁、谁直接出声，共 32 种连线方式。
- **包络（Envelope / EG）**：一个音从按下到松开，音量（或音高）随时间变化的曲线。

FM 的声音 = 用一些算子去"调制"另一些算子的频率，再叠加输出。调制量、每个算子的音量、
包络快慢都会明显改变音色。

## 1. 屏幕布局

```
┌──────────────────────────────────────────────┐
│ 1 PERF │ 2 ALGO │ 3 OSC │ 4 EG │ 5 LFO │... │  ← 顶部页签
├──────────────────────────────────────────────┤
│  状态行：P01 音色名  V096  O+0  A05  3V       │
│              当前页面的内容                    │
└──────────────────────────────────────────────┘
```

- 顶部 8 个页签随时可点；第 2 行是状态行：`P01` 音色号、音色名、`V096` 主音量、
  `O+0` 八度、`A05` 算法号、`3V` 正在发声的声部数。
- 点一行 = 选中（橙色高亮），再用**底部控制条**的大 `-` / 滑条 / 大 `+` 改值。

### 通用操作

| 操作 | 效果 |
|---|---|
| 点页签 | 切换页面 |
| 点某一行 | 选中（只选中，不改值） |
| 底部左侧 `<<`（黑色块） | 选中行减一 |
| 底部右侧 `>>`（黑色块） | 选中行加一 |
| 按住大 `-` / `+` 约 1.5 秒 | 开始连续改，松开停止 |
| 点/拖动底部滑条 | 直接设置选中行的值（右侧显示当前值） |
| 点 `1 PERF` | 回演奏页 |

> 参数改动只存在内存：换音色会重装该音色原始参数，关机全丢。想留住就存用户槽（7 NAME）。

## 2. 演奏页（1 PERF）

- 左边大框：波形示波器（WAVE）或李萨如（XY），用 `VIEW` 切换。
- 中间竖条：输出电平，越高越响，顶到红色表示削波。
- 下面 6 根柱子：6 个算子当前的包络电平。
- 底部键盘：25 键，点/滑可弹奏。
- 右侧快捷键：`PRESET`（换音色）、`VOLUME`（主音量）、`OCTAVE`（八度 -3..+3）、
  `PANIC`（全音关）、`VIEW`（波形/李萨如）、`XY DELAY`（余辉长度）、`AUTO`（示波器自动增益）。

## 3. 算法页（2 ALGO）

- `ALGORITHM`：算法 1..32，换算法 = 换 6 个算子的连线。
- `FEEDBACK`：反馈 0..7，算子用自己的输出调制自己，越大越粗糙/金属。
- `OSC SYNC`：算子同步开关，音高变化时波形硬同步。
- `TRANSPOSE`：整体移调 0..48 半音。
- 下方是当前算法的**算子连接图**（Dexed 风格）：
  - **绿色方框** = 载波，放在最下排，直接接到 `OUT`；
  - **蓝色方框** = 调制器，放在载波上方，用线连到它调制的算子；
  - 框里的数字是 OP1～OP6；右侧的直角回环表示该算子有自反馈；
  - `OUT` 在右下方，表示这些载波进入最终输出。
  图会随算法/反馈实时变化；同一种算法可能和 Dexed 的排版略有不同，但连接关系一致。

## 4. 算子页（3 OSC）

先点 `OP1`～`OP6` 选算子，再编辑：

| 参数 | 通俗解释 |
|---|---|
| `MODE` | `RATIO`：频率是基准音的整数/半整数倍；`FIXED`：固定频率（噪音/金属声常用） |
| `COARSE`/`FREQ` | RATIO 下的倍数；FIXED 下的固定频率档 |
| `FINE` | 微调 0..99，让算子稍微跑调，声音更厚 |
| `DETUNE` | 细微失谐 -7..+7，多算子叠加时有合唱感 |
| `LEVEL` | 该算子输出音量 0..99 |
| `RATE SCALE` | 高音区包络是否变快 0..7 |
| `VEL SENS` | 力度灵敏度 0..7（弹得越重越响） |
| `AM SENS` | LFO 对音量的调制深度 0..3 |
| `KEY BP` | 键位缩放断点（以哪个键为中心） |
| `L/R DEPTH` | 断点左/右的音量衰减量 |
| `L/R CURVE` | 左/右衰减曲线形状（-LIN/-EXP/+EXP/+LIN） |
| `ENABLE` | 算子开关；关掉等于从音色里拿掉 |

页面底部 `ROUTING (ASCII)` 用 3 列×2 行 ASCII 方框快速显示 6 个算子的 `OUT`/`IN`/反馈，
调参数时不用切页。

## 5. 包络页（4 EG）

- **AMP EG（音量包络）**：控制该算子从按下到松开的音量。
- **PITCH EG（音高包络）**：控制整个音的音高变化（打击乐"咚"、铜管"哇"常用）。
- 点 `OP1`～`OP6` 选算子；`AMP EG / PITCH EG` 文字是模式指示，点右上区域可切换。

| 参数 | 通俗解释 |
|---|---|
| `RATE 1..4` | 第 1～4 段的变化速度，越大越快 |
| `LEVEL 1..4` | 第 1～4 段结束时的音量目标 |

按下琴键后音量走 4 段：起音（R1→L1）→ 衰减（R2→L2）→ 按住（R3→L3）→ 松开（R4→L4）。

**页面布局**：
- 左列 `RATE 1..4`，右列 `LEVEL 1..4`（PITCH 模式下右列是 `TARGET 1..4`）。
- 下方 **6 张包络图**，对应 OP1～OP6（左上到右下：OP1/OP2/OP3 在上排，OP4/OP5/OP6 在下排，图内有 OP 编号）；
  方框是面板、网格是刻度、亮线是曲线、暗红色区域是包络电平。
- RATE 越大该段越短、线越陡；RATE 越小越平缓（四段宽度按 RATE 非线性分配）。
- PITCH 模式里 `TARGET 1..4` 是四段目标音高，`50` = 原音高，小于 50 向下滑、大于 50 向上滑。

## 6. LFO 页（5 LFO）

LFO 是自动来回摆的低频振荡器，用来做颤音/哇音。

| 参数 | 通俗解释 |
|---|---|
| `WAVE` | 波形：三角/锯齿/方波/正弦/采样保持 |
| `SPEED` | 摆动速度 |
| `DELAY` | 按下后多久开始摆动（延迟颤音） |
| `P MOD DEPTH` | 音高抖动深度（颤音） |
| `A MOD DEPTH` | 音量抖动深度 |
| `P MOD SENS` | 全局音高调制灵敏度 0..7 |
| `LFO SYNC` | LFO 是否随按键重新开始 |
| `KEY SYNC` | 每个音是否从波形起点开始 |

## 6.1 FX 页（6 FX）

- 顶部 FILTER / REVERB / DELAY / DIST / CHORUS / PHASER 选择效果器（与实机顺序一致）。
- FX MASTER：整条效果链总开关；OFF 时逐位直通，和没加效果器完全一样。
- EFFECT：当前效果器开关。
- TYPE：FILTER 的 LOW PASS/BAND/HIGH PASS，或 REVERB 的 ROOM/HALL/PLATE；
  没有类型的效果器显示 --。
- 三个参数行：DIST = GAIN/TONE/MIX；FILTER = CUTOFF/Q；其余为 FREQ/DEPTH/MIX、
  DECAY/RATE/MIX、DECAY/MIX。
- 六个效果器可独立开关，按 FILTER、REVERB、DELAY、DIST、CHORUS、PHASER 顺序串联；链尾有软限幅。
- 每个按钮下面直接显示 `ON`/`OFF`；按钮之间的 `>` 表示信号处理顺序：
  `FILTER > REVERB > DELAY > DIST > CHORUS > PHASER`；右上角是 FX MASTER 总开关状态。

### 效果器在做什么（简单版）

- **DIST（失真）**：GAIN 控制进入 tanh 软削波的驱动量，TONE 决定保留多少高频；
  MIX=0 是原声，MIX=99 是全失真。失真声会自动向原声响度靠拢，适合做脏音色/电吉他感。
- **FILTER（滤波）**：一个可调截止频率的滤波器。LOW PASS 只留低频、BAND 只留中频、
  HIGH PASS 只留高频；CUTOFF 是转折点（30 Hz–8 kHz），Q 越大转折点附近越"尖"（有共振）。
- **CHORUS（合唱）**：把信号复制一份，用 LFO 让复制品的延迟在 8–16 ms 间缓慢摆动，
  再和原声混合；FREQ 是摆动速度，DEPTH 是摆幅，MIX 是混合量。听起来像多个乐器齐奏。
- **PHASER（移相）**：4 级全通滤波器让不同频率产生不同相位，再和原声叠加形成会移动的
  "梳齿"（相位抵消）；FREQ 是扫描速度，DEPTH 是扫描范围，MIX 是混合量。
- **DELAY（延迟）**：把声音延迟一段时间再放出来，并送回输入端形成回声；RATE 是延迟时间
  （40–670 ms），DECAY 是反馈量（回声次数/长度），MIX 是干湿比。
- **REVERB（混响）**：用多个不同长度的延迟（梳状）叠加出密集反射，再用全通扩散；
  TYPE 切换 ROOM/HALL/PLATE 的空间尺寸/密度，DECAY 是尾音长度，MIX 是干湿比。

## 7. 名字/用户槽页（7 NAME）

- 上排 10 个字符是当前音色名；点字符选中，用右侧 `-` / `+` 换字符。
- `SLOT -` / `SLOT +` 选择 8 个用户槽之一。
- `SAVE`：把当前全部参数（全局 + 6 算子 + Pitch EG）存进当前槽。
- `LOAD`：把槽里的参数读回来。
- 槽数据在内存里，关机也丢；但切音色不会丢（切回来 LOAD 一下）。

## 8. 主题页（8 UTIL）

点一下切换 `GRAPHITE`（红）/ `AMBER`（琥珀）/ `ICE`（青）。主题会同时改变界面、波形、
李萨如、电平条、包络曲线和键盘的颜色。

## 9. 常见问题

- **没声音**：点 `PANIC` 重弹；检查 `VOLUME`；确认算法里有载波（全去调制别人可能没输出）。
- **声音破**：电平条顶红，降低 `VOLUME` 或算子 `LEVEL`。
- **按键一直响**：点 `PANIC`。
- **改完参数换音色就没了**：正常，先 `SAVE` 到用户槽再换。
- **按 `-`/`+` 没反应**：确认该行橙色选中；按住 1.5 秒才开始连发。
- **EG 显示和 PC 编辑器差 1**：0..99 与内部定点换算取整导致，声音是对的。
- **算法图出现橙色方框/箭头**：这是真实路由示意；OP 编号在方框里，反馈在方框左侧回环。
