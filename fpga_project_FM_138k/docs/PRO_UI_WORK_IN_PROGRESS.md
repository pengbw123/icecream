## 已写入但尚未整体交付

- `pro_audio_effects.v`：后置滤波/失真/原 chorus/reverb 的候选链路。
  **当前 top_138k 未启用 PRO_FX_ENABLED，音频仍走原声旁路。**
- `seg8_status.v`：8 位数码管串行驱动候选模块。尚未接顶层、引脚约束。
  板厂例程 HC595：DS=M18、ST_CP=C2、SH_CP=F4，须再次核对后集成。
- `rtl_menu_text.v`、`font8x16.mem`：RTL 字符栅格化准备。
  当前固件仍为原性能页，没有多页专业编辑菜单。`ENABLE_MENU_TEXT=0`
  暂时不例化此候选模块；独立综合发现字符存储展开为约 2.2 万寄存器，
  正式启用前必须改为实际 BSRAM（必要时显式 SDPB），不能直接打开此参数。
- UI 内部命令口、文本/配色寄存器、软核存储扩容是后续菜单准备工作，
  不代表所有参数已可在屏幕操作。
- `pro_tables.h`、`generate_pro_ui.py`：参数转换表准备。
  需补查 fixed 模式 detune 转换，再接入菜单；禁止直接宣称 Dexed 全兼容。
