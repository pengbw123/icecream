# ACG720 板载耳机监听（2026-10-23）

`top_138k` 与 `top_138k_hdmi` 均已接入板载 ES8388。耳机接 **OUT1** 音频输出插孔，
不要接 IN1 或 MAX98357 的扬声器端子。ES8388 与 MAX98357 接收同一个最终 I2S 数据流，
左右声道都是当前单声道混音，音量由原来的主 VOLUME 控制。没有新增独立耳机音量。
两种输出电路的模拟增益、负载不同，相同的数字样本不代表相同的听感声压。

## 实现与引脚

新增 `src/es8388_output.v`，包含时钟分频、初始化寄存器序列和开漏 I2C 写入器。
编解码器数字增益及 OUT1 模拟增益固定为 0 dB，关闭模拟输入旁路、立体声增强和去加重。
ADC 与麦克风模拟路径关闭；OUT2 未启用。

| 信号 | FPGA 管脚 | 用途 |
|---|---|---|
| aud_mclk | V20 | 50 MHz / 4 = 12.5 MHz，256 Fs |
| aud_bclk | U20 | 3.125 MHz，64 Fs |
| aud_lrclk | W20 | 48.828125 kHz |
| aud_dacdat | AA20 | 标准 I2S，16 位数据、每声道 32 位时隙 |
| codec_scl | M13 | 板载共享 I2C，开漏输出/输入采样 |
| codec_sda | M16 | 板载共享 I2C，开漏输出/输入采样 |

地址为 7 位 `0x10`（写地址字节 `0x20`）。SCL/SDA 配置 FPGA 上拉，正常总线速率约 100 kHz。
FPGA 作为音频时钟主机，ES8388 为从机；板卡教材的回环例程使用 ES8388 主模式，
不能直接照抄其 `0x08=0x84` 时钟设置。

ES8388 上电默认主模式，因此 FPGA 在从模式寄存器得到 ACK 前将 BCLK/LRCK 引脚置为高阻。
之后复制现有 I2S 时钟和数据，避免改动原来的采样节拍与 FM 音高。

## 上电与故障处理

- 主复位释放后等待 10 ms，再复位/配置 ES8388；
- 配置期间保持 DAC 静音与 OUT1 衰减，释放转换器后等待 500 ms；
- 最后启用 OUT1、设置固定 0 dB 增益、解除静音；
- 每个地址/寄存器/数据字节检查 ACK，失败后间隔 20 ms 从头重试；
- 支持 SCL 时钟拉伸和超时退出；SDA 被中断传输拉低时先发最多九个恢复时钟及 STOP；
- 初始化独立于音源、UI 和 MAX98357，编解码器缺失不会阻塞它们。

内部 `u_codec.ready` 表示全部初始化写入完成，`u_codec.init_error` 表示重试期间发生错误。
这两个信号可用于 GAO 调试，没有添加新的屏幕控制。

## 验证与实机检查

`sim/tb_es8388_output.sv` 用 I2C 从机模型核对初始化寄存器、NACK 后完整重试、时钟拉伸，
并解析实际 I2S 帧，检查左右声道与原输出一致、样本幅度改变和静音同步。
`sim/tb_es8388_i2c_faults.sv` 检查 SCL 卡低超时、九时钟恢复和设备不应答时的引脚释放。
两项均加入 `sim/run_checks.ps1`。

双屏烧录文件为 `impl/pnr/fm_138k_rgb_hdmi.fs`，该版本同时驱动 RGB、HDMI、
MAX98357 和板载 ES8388。单 RGB 工程仍可用 `build_cli.tcl` 独立构建。

## 2026-10-23 输出选择

SETUP → AUDIO OUTPUT 选择 SPEAKER 或 HEADPHONE；默认 SPEAKER。
与旧版两路同时镜像不同，当前未选一路由 I2S 发送数字静音（时钟不停），选择按完整立体声帧锁存。
耳机和音响共用主音量，当前上电主音量为 5。此功能不检测耳机是否插入。
