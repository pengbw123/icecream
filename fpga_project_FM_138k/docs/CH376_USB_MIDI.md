## 硬件与使用

这是 **外接 CH376S 模块通过 SPI 接 138K** 的 USB Host。
键盘接 CH376S 的 USB-A；ACG720 原有 USB 设备接口不因此变成键盘主机。
支持 USB MIDI 1.0、全速 Bulk IN；不支持 Hub、MIDI2/UMP 和厂商私有协议。
实际键盘兼容性仍需实机验证。

适用于队友文档确认的 HW-252/HW-252A、2×8 排针板型：

| 模块丝印 | 功能 | ACG720 排针 | FPGA 引脚 |
|---|---|---|---|
| D3 | SCS / CS# | P7-5 | A18 |
| D5 | SCK | P7-7 | F13 |
| D6 | SDI / MOSI | P7-8 | F14 |
| D7 | SDO / MISO | P7-13 | C13 |
| INT | INT# | P7-14 | B13 |
| GND | 公共地 | P7-12（或 P7-30） | GND |
| VCC | 模块及键盘供电 | 合适的 5V 电源 | 非 FPGA IO |

按 HW-252A 的 SPI 模式接线：断电后取下 P_S 模式帽，WR/RD 接模块 GND，
使用 **D3** 作 SPI 片选，另一个标记 CS 的并口引脚不用；并口 CS/A0 及其他未用并口数据针不接。
S 组 UART TXD/RXD 不接。改变模式后重新上电。
不同板型以实际模块资料为准，不能只看 CH376S 芯片型号照搬跳线。
GPIO0 VCCIO 必须为 3.3V，模块 SDO/INT 电平也须适配 3.3V。
独立 5V 给模块/键盘供电时，与 FPGA 共地，不再并接板上 5V。

P7-1/2/3 音频和 P7-6 灯带保留；P7-4 的 25K 桥接线不再需要。
两个 wrapper 默认 `LEGACY_BRIDGE_ENABLED=0`，需要历史对照时才显式改为 1 并重建。

## 状态与接口

- D5：CH376 SPI 存在性探测成功。
- D6：USB MIDI 配置成功，可接收数据。
- D7：`fault_code!=0`，包括模块缺失、枚举错误和断线恢复过程。
- D0..D4 保留原含义，默认禁用桥接后其丢事件灯不再使用。

上电自动枚举，不需要手机命令；触摸、PC CH340、ARP、SEQ、练习模式与双屏功能继续使用本地实现。
USB 拔出后发送 CC64=0、CC123=0，再恢复检测；当前音源延音/清音仍为全局语义，
因此可能一并释放触屏和自动演奏声音。没有声称多来源清音已完全隔离。

## 与队友版本的适配差异

1. **力度**：USB 通道 1 的非零 Note On 以 0..80 → 0..127 校准一次；原始 0 仍为松键。
   打击垫通道和其他 MIDI 通道不缩放，触屏力度也不缩放。队友默认 90 已改为本工程的 80。
2. **标记字节**：USB header（cable/CIN）进入 MIDI 入口时清零，保留 status/data1/data2。
   避免 cable 8..15 与本工程内部 bit31 示范、bit30 ARP 标记冲突；内部自动事件标记继续保留。
3. **仲裁与背压**：USB、可选历史桥接、UI 使用轮转仲裁和保持槽。
   再增加两项寄存器 FIFO，输入 ready 只依赖已寄存的占用数，切断下游控制到上游 ready 的组合路径。
   满队列同时出队时下一周期再接收，允许一个空拍，保持无丢失、无重复和暂停时数据稳定。
4. **音频**：继续使用本地 32×6 FM、六效果器、ES8388 和现有音量/输出选择。
5. **时钟**：全在 50MHz 域，MISO/INT 同步；SPI 约 1.25MHz；没有启用旧 USB 软核、额外 USB PLL 或其 RAM。
