# FM-1 六效果器实现说明（给后续 AI / 开发者的交接文档）

本文只写**当前项目真实需求、原理、参数作用、已有实现和待办**，目的是让另一个 AI 不用翻大量历史对话就能继续改。

---

## 0. 权威需求：以实机为准

用户手里有一台 **M-VAVE FM-1**，实机有 **6 个可独立开关的效果器**，面板/参数顺序固定为：

```
FILTER -> REVERB -> DELAY -> DISTORTION -> CHORUS -> PHASER
```

注意：

- 这是**信号处理顺序**，也是 FX 页按钮从左到右的顺序；
- 6 个效果器**互相独立**，可以同时开任意多个（允许双开/全开），不是二选一；
- 之前项目根目录的 `M-VAVE_FM1_全套效果器_FPGA_实现工程文档（AI生成代码专用）.txt`
  把顺序写成 `Filter -> Distortion -> Chorus/Phaser -> Delay -> Reverb`，且声称 Chorus/Phaser 互斥，
  **这两点和实机不符，不要按它改**；
- M-VAVE 官方开源工作台只暴露了共享混响/延迟，不能代表整机 FX 全貌；
  **本文的 6 效果器顺序和参数以用户实机为准**。

目标：在这块 FPGA 上**尽量还原实机六效果器的原理、参数作用和听感**，不要求逐样本复刻原厂代码。

---

## 1. 系统与代码位置

- 音频采样率：`48.828125 kHz`（`sample_tick` 每 1024 个 50 MHz 时钟一次）。
- 音频格式：16-bit signed，内部可用 24/32/40/48-bit 中间结果。
- FX RTL：`src/audio_fx.v`（链、寄存器、滤波、失真、软限幅）。
- 子模块：
  - `src/audio_chorus.v`
  - `src/audio_phaser.v`
  - `src/audio_delay.v`
  - `src/audio_reverb.v`
- 参数表：`src/generated/fx_*.mem`，由
  `tools/generators/generate_audio_fx_tables.py` 生成。
- UI 固件：`src/ui_firmware/main.c`，FX 页 `draw_fx()/adj_fx()/load_fx()`；
  写寄存器用命令 `0x70`，回读用 `0x69` 地址 `0x200+addr`。
- 约束：所有效果器都在**一个 sample_tick 内**用多周期 FSM 完成；不能用浮点。

### 1.1 当前链路（已实现）

```
dry
 -> FILTER
 -> REVERB
 -> DELAY
 -> DISTORTION
 -> CHORUS
 -> PHASER
 -> soft limiter
 -> sample_out
```

- 6 个 enable 全关，或 FX master 关，或 bypass 打开：输出**逐位等于 dry**；
- 否则输出经过整条链 + 链尾软限幅（>0.75 FS 后 1/4 斜率压缩，最后饱和到 16-bit）。

## 3. 每个效果器的原理、参数作用与当前实现

### 3.1 FILTER（第一个）

**原理**：可调截止频率的滤波器，放在最前，先塑造进入混响/延迟/失真的频谱。
实机有三种模式：Low Pass / Band Pass / High Pass；Cutoff 控制转折点；Q 控制转折点附近的共振峰。

**参数作用**：

- TYPE：
  - LP：保留低频，切高频；
  - BP：只保留中间频段；
  - HP：保留高频，切低频；
- CUTOFF：0..99 映射到频率，数值越大通过的频率越高；
- Q：0..99，Q 越大，转折点越尖、共振越明显。

**当前实现**：

- 用 Chamberlin 状态变量滤波器（LP/BP/HP 三选一）；
- 截止频率目前映射 **30 Hz .. 8 kHz**（受 Chamberlin 稳定性限制）；
- Q 约 0.5..12；
- 参数已加平滑。

**待办/目标**：

- 实机/市场 FM 合成器一般到 **20 Hz..20 kHz**；需要换 TPT SVF（g=tan(πfc/fs)）或 Biquad，
  保证 20k 附近稳定。换 TPT 需要处理每采样除法，建议参数变化时用小除法 FSM 算系数。

---

### 3.2 REVERB（第二个）

**原理**：多个不同长度的梳状延迟（Comb）并联，形成密集反射；再用全通（Allpass）扩散；
Decay 控制反馈量，Mix 控制干湿。实机有 Room / Hall / Plate 三种空间。

**参数作用**：

- TYPE：三套延迟长度/反馈/阻尼配置；
  - ROOM：短、紧凑；
  - HALL：长、空旷；
  - PLATE：明亮、金属感（DX7 常用）；
- DECAY：0..99，越大尾音越长；本质是梳状反馈系数；
- MIX：0..99，干湿比。

**当前实现**（`src/audio_reverb.v`）：

- 4 个独立反馈的梳状延迟 + 2 个串联全通；每种 Type 使用不同延迟长度；
- 基础反馈表 0.50..0.90，HALL 加 0.04、PLATE 加 0.02，最高限制约 0.96；
- 梳状反馈有一阶阻尼；Q12 状态的 DC 阻断器避免整数截断留下永久偏移；
- MIX=0 逐位直通，三种 Type 的尾音与 DECAY 参数已做脉冲仿真。

**后续可改进**：

- 实机复测 ROOM/HALL/PLATE 的听感与 RT60，按听感再调反馈和阻尼；
- TYPE 突变时旧延迟线内容可能带来瞬态，需要根据实机操作频率决定是否交叉淡化；
- 若仍嫌尾音稀疏，再考虑更多全通级数，并检查 BSRAM 与时序余量。

---

### 3.3 DELAY（第三个）

**原理**：环形缓冲 + 反馈递归；把声音延迟一段时间再放出，并送回输入形成回声。

**参数作用**：

- DECAY：反馈量，0..99，越大回声重复越多、尾越长；
- RATE：延迟时间，0..99，数值越大间隔越长；
- MIX：0..99 干湿比。

**当前实现**（`src/audio_delay.v`，2026-10-23）：

- 65536 样本环形延迟线，16 位地址；时间 **20..1000 ms**（977..48828 样本）；
- DECAY 仍映射反馈 **0.30..0.90**，0 表示最短衰减，并非关闭反馈；
- RATE 改变采用两个固定读抽头、512 个采样间隔（约 10.49 ms）的线性交叉淡化；
  淡化期间不再移动抽头，完成后再接受最新目标，避免上游参数平滑造成连续跳址；
- 反馈从淡化后的湿声取得，加入 Q12 一阶低通（系数 1/2），写入使用饱和加法；
- 反馈乘积正负都向零截断，避免负一个最低位无限循环；
- 两个抽头各自检查写入历史，复位不清整块 RAM，也不会读出上电未知内容；
- MIX=0、enable=0 为逐位原声；关闭时内部延迟线继续运行，再开启会保留最近的声音历史。

**验证与后续**：

- `sim/tb_delay_phaser.sv` 检查最短/最长脉冲位置、环形地址回绕、负尾音归零、
  高反馈饱和、调时间连续性和直通；
- 交叉淡化能减少跳址咔哒，切换时仍可能听到两段历史声音短暂叠加，实机待听。

---

### 3.4 DISTORTION（第四个，重点）

**原理**：前置驱动把信号推进 tanh 非线性区，产生谐波；再低通塑形（TONE）；
自动匹配处理前后的平滑响度，最后用 MIX 混合原声与失真声。
实机原则：**GAIN 改变失真度，开启失真后输出响度应接近输入；MIX 不应成为总音量。**

**参数作用**：

- GAIN：0..99，控制进入非线性的驱动量；越大谐波越多、声音越粗；
- TONE：0..99，失真后的低通，低值闷、高值亮；
- MIX：0..99，0 为原声，99 为全失真，保持接近原声的整体响度。

**当前实现**（`src/audio_fx.v`）：

- 归一化 tanh：`y = tanh(drive*x) / tanh(drive)`；
- 512 点 tanh LUT（z=0..8），相邻表项做线性插值，drive 1..8（Q8），
  由 `fx_tanh_lut.mem` / `fx_dist_drive.mem` / `fx_dist_makeup.mem` 提供；
- makeup 表为 `1/tanh(drive)`，使用 Q2.14（系数可大于 1）；旧 Q1.15 表全部被截到
  `0x7FFF`，等于没有进行归一化；
- TONE 为一阶低通（500 Hz..12 kHz）；
- 用输入和失真后的平滑绝对值包络调整湿声增益，只做衰减，抑制 tanh 峰值归一化
  在低幅度处造成的过大增益；静音后按 GAIN 的预置系数启动，避免音符起音瞬间暴响；
  寄存器 8 改为 Q15 干湿混合；
- 已修五个波形/参数 bug：
  1. 负半周取绝对值用无符号减法导致正负不对称、单边削顶；
     现在用 `{sign,value}` 符号扩展后取绝对值；
  2. 参数平滑整数右移 8 位变成 0，参数实际不动；
     现在用 Q8 状态（24-bit）平滑，约 5 ms。
  3. LUT 直接取整导致低幅度波形明显呈阶梯；现在使用 17 位小数做线性插值。
  4. Q8 平滑器把无符号状态与负差值相加，向下调旧 LEVEL 时状态反向溢出，
     索引钳成 99；现在移位和加法都在有符号 25 位中完成。
     同一个平滑器供所有连续 FX 参数使用。
  5. 旧版峰值归一化使 GAIN 50 时中等幅度正弦的 RMS 约为原声 2.07 倍；
     已改为动态响度匹配，并将旧 LEVEL 改为 MIX。实机听感仍需验证。
- 旧版本的 ±10000 直流、0.8 FS 正弦数值记录不适用于这次修正后的位流；
  需重新实机测量波形、音量及听感。

**注意**：

- 响度匹配使用约 5 ms 平滑绝对值包络，是近似的平均响度匹配；
  它不能保证所有音色、瞬态与频率的主观响度完全相同。
- 失真在 DELAY 之后，所以它也会处理混响/延迟的尾音，这是实机顺序。

### 3.5 CHORUS（第五个）

**原理**：LFO 调制短延迟线的读指针，制造微小音高抖动；干声 + 湿声叠加使声音变厚。
实机/市场 chorus 常见结构：低频 LFO、短延迟线、Depth 控制摆幅、Mix 干湿。

**参数作用**：

- FREQ：LFO 速度，0..99，越大越快；
- DEPTH：延迟摆动幅度，0..99，越大越厚/越飘；
- MIX：干湿比，0..99，通常不做 100% 湿（会失去干湿拍频）。

**当前实现**（`src/audio_chorus.v`）：

- 2048 样本延迟线；
- 16 位相位三角 LFO，约 0.05..6 Hz；
- 两个互补调制抽头，基础延迟约 8.2 ms，Depth 最大增加约 8.1 ms；
- 每个抽头做 Q8 分数延迟线性插值，四次同步 RAM 读在一个样本周期内复用；
- 每个抽头独立检查延迟线预热，避免上电时读取未写入的 RAM；MIX=0 逐位直通；
- 默认 freq30/depth40/mix30。

**验证与后续**：

- 仿真检查了两个抽头的脉冲位置、快速 LFO 下的相邻采样连续性和 MIX=0 直通；
- MIX=99 为纯湿声，用户若需要干湿拍频应降低 MIX；
- 实机仍需确认默认值的听感；如要改成正弦 LFO，可复用现有相位累加器并增加查表。

---

### 3.6 PHASER（最后一个）

**原理**：多级一阶全通滤波器（APF）级联，LFO 扫全通系数，使不同频率相位变化；
与干声叠加形成移动的相位抵消（“抽吸”）。不使用延迟线。

**参数作用**：

- FREQ：LFO 扫描速度；
- DEPTH：扫描幅度/相位变化范围；
- MIX：相位效果强度；0 为原声，99 为 50% 原声 + 50% 全通声，产生最深陷波。

**当前实现**（`src/audio_phaser.v`）：

- 4 级全通，状态为带 4 个保护位的 Q8，减少低电平量化和中间级削顶；
- FREQ 为 0.05..3 Hz 三角 LFO，使用 16 位调制值；
- 全通采用 `y=a*x+x[-1]-a*y[-1]`，系数从 120..4500 Hz 对数频率表插值得到；
  上述中低频范围对应负系数，旧实现使用正系数时扫动集中在较高频率；
- DEPTH=0 固定在约 740 Hz，DEPTH=99 扫描接近整个频率范围；
- 上游参数 Q8 平滑外，系数增加 Q8 平滑，避免查表台阶；
- 系数调制、查表与插值分周期执行，每样本约 21 个系统时钟，避免组合路径超过 50 MHz 时序预算；
- MIX 湿声权重限制到约 1/2。旧 MIX=99 是纯全通声，固定系数时幅频基本平坦，
  会失去干湿抵消形成的典型 phaser 陷波；现在 MIX 越大，相位抵消越明显；
- `sim/tb_delay_phaser.sv` 验证 DEPTH=0 时约 309 Hz 的陷波及 750 Hz 通带、
  最大速度/深度、越界参数钳位、静音恢复与逐位直通。

**目标**：

- 如实机需要，可扩为 6 级全通（增加陷波数量）；
- 正弦 LFO，范围与实机对齐；
- 干湿混合，无反馈自激。

## 4. 全局设计规则（必须保持）

1. **链路顺序不可改**：
   `FILTER -> REVERB -> DELAY -> DISTORTION -> CHORUS -> PHASER`。
2. **6 个 effect enable 完全独立**，允许同时开；不要强制互斥。
3. **FX master 关 / bypass / 全部 enable 关** 时输出必须逐位等于 dry。
4. **参数平滑**：所有连续参数用约 5 ms 一阶平滑（Q8 状态，不要用整数右移直接截断）；
   enable/type 可以立即生效。向上调参的最后一个 Q8 单位内仍需每次前进一个最低位，
   否则整数部分会永久停在目标减一（例如 UI 99，内部 98）。
5. **增益/混合解耦**：失真 GAIN 主要改谐波，MIX 改干湿比；不得出现负半周不对称。
6. **防止溢出**：所有乘法中间结果位宽足够；加法/输出饱和；链尾软限幅。
7. **定点**：不使用浮点；参数表由 Python 生成，不要手改 mem（改生成器再重新生成）。
8. **UI 顺序 = 链顺序**：`FILTER > REVERB > DELAY > DIST > CHORUS > PHASER`。

- Fmax 54.825 MHz（50 MHz 时钟）、40.844 MHz（像素域），setup/hold TNS 均为 0。

改动时请保持这些余量，尤其混响/延迟扩 BSRAM 和滤波除法器的时序。

## 7. 常见坑（前车之鉴）

1. **负数取绝对值**：不要用 `17'd0 - {1'b0, signed16}`；会得到错误大数。
   正确：先 `{sign, value}` 符号扩展成 17 位 signed，再取负。
2. **参数平滑**：`(target-cur) >>> 8` 在 0..99 整数上等于 0；必须用 Q8/Q16 状态。
   Q8 状态虽为非负数，与负差值运算时也必须先扩成有符号数，否则向下调参会反向溢出。
3. **链顺序**：不要按旧文档的 `Filter->Dist->Chorus...` 改回来。
4. **UI 顺序**：按钮/箭头必须和链顺序一致，否则用户看到的和听到的不一致。
5. **失真增益补偿**：makeup 表使用 Q2.14，RTL 乘积右移 14 位；改表或改位宽时须一起修改，
   再测 `GAIN 20/99` 的峰值/RMS，防止再次出现“开失真音量暴涨/骤降”。
6. **改参数表**：只改 `tools/generators/generate_audio_fx_tables.py`，重新生成所有 `fx_*.mem`，不要手改。
7. **位流重建**：改 RTL 后必须重新跑 `gw_sh build_cli.tcl`；只改固件不需要重跑 PnR。
