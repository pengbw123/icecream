# 手势旋律演奏模式

进入SETUP → AI BASS → COMPOSE → SETTINGS → GESTURES。MODE按钮在BASIC和PERFORM之间切换，切换会关闭CONTROL，需用户再次打开。RECOGNITION关闭时不能开启CONTROL。

BASIC保留握拳停止、张掌开始、V变奏。PERFORM中张掌启动或在下一小节恢复生成，握拳在下一小节循环最近一个完整16步小节，V在下一小节退出循环并提高一小节变奏强度。首次还没有完整小节时，握拳等待第一个完整小节。持续同一姿态沿用原有去重，不重复发命令。

原四小节LOCK仍可通过触屏使用；手势循环和恢复会撤销四小节回放。新小节缓存用两组16步，循环时冻结读银行；保留音高、力度和门控信息。小节起点遇到跨小节延音时，转换为可独立回放的起音。门控仍按既有1/2/4/8步编码，跨界剩余长度可能向下取整到该编码。

仅稳定且当前帧通过的张掌会更新位置。计算16x16二值轮廓重心，左右三档控制密度24/64/110，上中下三档控制方向110/64/24；每轴有迟滞，在下一拍提交参数。上下控制上行/下行倾向，不是保证绝对音高。拒识或移开手保持最近音乐参数；CONTROL关闭后不再更新。录入节奏时起音位置仍由已录32格节奏决定，密度不能覆盖节奏锁定。

手动停止、打击垫、模式切换及紧急停止优先；手动参数编辑会清除未提交的手势参数。原有NoteOff输出队列保持背压协议，不取消已经发出的待接收MIDI包。触屏状态LOCKED也反映手势小节循环，LOCK AT END反映等待循环边界。

接口：辅助寄存器3C7 bit0选择演奏模式；UI63写bit2控制位置功能，bit0识别、bit1控制保持原义。UI63读布局保持不变，菜单本地保存模式。手势动作8/9/10为X左/中/右，11/12/13为Y上/中/下，仅PERFORM接收；2/3/4仍代表张掌/握拳/V。模式默认BASIC。

模型、训练权重和摄像头初始化未修改。节奏预备拍专项测量为16个步长加一个状态切换时钟，没有额外十六分音符。本轮最终综合布线、资源和发布状态以release记录为准。
