# 138K RGB 迁移总结（2026-10-18）

> **数字已过期（2026-10-20 注）**：本文的资源、Fmax、软核容量来自 2026-10-18 19:53 的构建。当前工程以 `impl/pnr/fm_138k_rgb.rpt.txt` / `fm_138k_rgb_tr_content.html` 为准；最新（2026-10-19 21:54，含 128 KiB 软核存储与 AUTO 增益）为 Logic 17657、CLS 13422、Register 10401、BSRAM 116/340、DSP 23.5/298，50 MHz 域 Fmax 52.782 MHz、33.333 MHz 像素域 Fmax 43.544 MHz。功能描述仍基本有效，容量数字不要再引用下文。

## 实现范围

保留 16 复音、6 算子、ROM1A 32 音色、CC64 延音、弯音、LFO、PC 串口编辑接口。FM 运算内核未改动；本次主要完成板级适配、输入仲裁、RGB/触摸菜单及灯条。

138K 的板载 USB 设备接口不能直接替代 USB Host。模块到货前，以独立 Primer25K 工程解析键盘，再以 1 Mbaud、8N1 专用 UART 发送事件。原 25K FM 工程不改。CH376S 接入及 USB-MIDI 主机驱动尚未实现。

当前 FM_AUDIO_ONLY=1，数字效果器旁路；HDMI、旧 SPI 屏不进入活动显示链路。未减少 16 复音。

## 硬件结构

- top_138k：板级复位、输入仲裁、音源、触摸菜单、RGB 和 WS2812。
- top：保留原音源/PC 协议；USB_HOST_ENABLED=0 去除原直连 USB 主机。
- rgb_visualizer：纯 RTL 800×480 RGB565、33.333 MHz 像素时钟，总时序 1056×525（约 60.125 Hz）。波形、算子 EG、峰值和琴键高亮直接渲染，无 DDR 帧缓存。
- 波形双银行各 512×8bit，写入与显示所有权由跨时钟握手切换，垂直消隐时发布；不把正在写的数据当整帧显示。
- touch_ui_controller：50 MHz RV32I、8 KiB 指令容量和 16 KiB 数据映像，仅轮询触摸和发 MIDI/菜单事件。加入XY菜单后的 UI 固件代码 5564 字节。
- gt9147_reset：移植 piano1 已验证的复位/INT 选址逻辑。触点就绪才读取，整帧读完才清状态；不写入猜测的 GT 配置。支持 5 个触点，屏幕弹奏力度暂固定 100，不模拟面积压力。
- ws2812_keys：25 灯固定 MIDI48～72。Note Off 灭灯反映物理按键，而非延音踏板尾音；CC120/123 清灯。50 MHz 下 T0H=400ns、T1H=800ns、位周期 1.26us。

屏幕基础菜单：32 音色切换、音量 ±5、虚拟键盘八度 -3～+3、PANIC。屏幕八度不改变外接 MIDI 键盘或灯条的固定映射。

最新新增 VIEW WAVE/XY 切换和 XY DELAY 1～96 样点调节。audio_xy_scope 用单声道当前PCM/延迟PCM画李萨如轨迹，双银行1bit位图共8KiB；不是FFT。视频PLL失锁时同步清理两侧缓存握手的风险已修复并有故障注入回归。详见 XY_VISUAL_UPDATE.md。

## 仿真及已解决的问题

- tb_138k_io：专用 MIDI 串口收发顺序、弯音/CC、反压及 WS2812 首灯数据/脉宽通过；保留的 TMDS 编码单元测试也通过，但 HDMI 已停用。
- tb_touch_ui：真实 UI 固件运行在 RV32I 上，以引脚级 I2C 模型验证探测、寄存器读取、菜单单次触发、按住不重复、无新帧不误松键、空触点帧正确释放。
- tb_rgb_visualizer：实际 RGB 输出捕获，验证 800×480 有效像素、无未知颜色、写显示缓存互斥；生成 tmp/rgb_preview.png。
- 初版文字 ROM 与字形组合路径过长，已插入寄存器分级；当前像素域 Fmax 为 40.111 MHz，仍满足33.333MHz。
- FPC 占用 CPU/SSPI 复用脚，必须启用 use_cpu_as_gpio/use_sspi_as_gpio，否则无法正确放置。
- 138K 使用 Arora V 的 PLL 原语，不能直接复用 25K 的 PLLA 配置。
- 禁用原 USB 主机后同时解除其看门狗对音源的复位影响，防止没有 USB 固件时周期性静音。

## 上板顺序

1. 断电接 FPC，检查排线触点方向，GPIO0 Bank 设 3.3V。先仅接屏幕、串口和音频。
2. 烧录 fm_138k_rgb.fs。S4 为复位。CH340 使用 115200/8N1，应输出 UI 启动及 GT 探测日志。
3. 确认图像稳定、TOUCH OK，测试菜单、屏幕多点琴键及松键。
4. 再连接 25K 中转 TX→P7-4，并共地。两板各自供电，不连接两板 5V。
5. 最后接有独立供电和电平转换的 WS2812 灯条。

状态灯：LED0 心跳，LED1 视频 PLL 锁定，LED2 近期 MIDI 事件，LED3 触摸已识别，LED4 中转事件溢出。
本版本没有实际烧录用户硬件；触摸仿真模型不能代替真实面板确认。
