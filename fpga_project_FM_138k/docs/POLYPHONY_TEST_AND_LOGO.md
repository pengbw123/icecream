# 32声部显示、多频测试与首页Logo

## 操作

1. 先选择已保存的正弦测试音色：算法32、仅OP1启用、RATIO 1.00、DETUNE 0、反馈0；关闭LFO调制和所有效果器，音高包络保持中性。包络需保持持续发声，关闭键盘幅度缩放，音色移调设为中性。
2. 关闭ARP、SEQ、AI、练习和曲谱播放，松开全部琴键并等待释放结束。首页选VOICES。
3. 按板载S0（F15）启动32音测试。4×8格按真实分配槽逐个亮起，顶部原有VOICE计数应到32。空闲格不亮；松键后的释放尾音仍占槽，结束后熄灭。
4. 点FFT先进入原对数频谱；再点FFT进入LIN FFT。线性模式显示真实FFT的0..511频点，横轴0..约24.4kHz，分辨率47.6837Hz，纵轴为固定dBFS，不做显示AGC。
5. 在任意页面再次按S0，或按S1（A20）停止。逐音NoteOff后额外发出仅针对LIVE part的All Notes Off，避免延音踏板使测试音挂住。此清理也会释放LIVE其它声音；测试开始要求所有声部空闲。

S0在首页VOICES或测试正在运行时用于测试，其它情况保留原曲谱功能。按住S0停止后不会顺带启动曲谱。未满足空闲条件时不启动。测试音不改用户选定音色、主音量；测试期间临时禁止滑音，停止后恢复。测试期间不要开启自动演奏或修改音色。测试占用引擎最终事件入口，普通音符不会挤占测试声部；被按住的实体键在停止后应重新释放再弹。

固定输出为MIDI 96..127，力度32。A4=440Hz、频率比1、无移调时范围2093.005..12543.854Hz。它们是用于区分谱峰的高音测试频率，不是音乐和弦。默认音量5较低，线性谱峰可能短；可逐步增加主音量观察，不要开启失真或使输出削波。幅度/调制/缩放会改变谱峰，32格本身只能证明活动槽状态，不能替代音频频谱证据。

## 实现

- 引擎导出32位真实voice_active状态，经视频时钟同步、帧边界锁存显示。每个格对应固定槽号，第一行槽1..8，以此类推，不通过活动总数模拟点亮。
- RTL test32采用valid/ready，受阻时保持事件，开始/停止中途操作均释放已发出的音。测试源经过同一FM32、效果器、主音量和I2S路径。
- 原1024点Hann FFT保留。增加512频点线性结果流，与64个对数频带共用变换；线性快照为双缓冲、帧边界切换，不阻塞音频。线性结果不使用频率表预画峰。
- GOWIN官方Logo位于首页(688,80)，64×24像素；两种官方颜色加白底，静态RTL行常量，无帧缓存/软核像素绘图。只在首页显示。来源和原图在assets/branding。
- 菜单ROM81776/81920字节，新增菜单空间余量很小。FPGA资源以最终布局布线报告为准。

sim/run_polyphony_checks.ps1：启动门控、交替背压、32个NoteOn、完整/中途停止、生产FM32加效果器通路真实32槽与释放到0、零抢占/零丢采样/零超时、4096个PCM样本的32个独立频谱峰、512频点输出及双缓冲恢复。

sim/tb_rgb_visualizer.sv +voices/+linear/+spectrum：32格实际状态、逐点Logo、线性频点定位和旧对数频谱。sim/tb_touch_ui.sv +spectrum：真实RV32I菜单及触摸切换五种视图。
