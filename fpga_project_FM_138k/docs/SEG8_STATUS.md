固定显示 `L xxP xx`，共 8 位。例：`L 50P 03` 表示窗口峰值约半满幅、3 个活动声部。
`L` 是 level，`P` 是 polyphony。小数点关闭。

- 电平来自 `top.monitor_sample`，是效果器、主音量之后，耳机/外放选择之前的最终 PCM。
- 每 40 ms 取绝对值峰值，四舍五入映射为 0–99。正满幅 32767 和负满幅 -32768 均为 99。
- 不是声压、不是 dB，也不是菜单主音量。降低主音量会使此值相应降低。
- 不自动增益，方便观察实际输出；很小的数字电平可能四舍五入为 0。
- 停止发声后，下一个完整静音窗口归零，含完整扫描刷新延迟不超过约 86 ms。
  混响、延迟尾音仍属于声音，继续计入电平。
- 复音计数直接取 FM 引擎活动槽数，包含释放阶段和 LIVE/BACKING；不是手指按键数。
  当前总上限 32，显示保留两位，越界时封顶 99。
- 驱动全为 50 MHz 同步 RTL，时钟使能扫描。移位时钟 50 kHz，
  每位 350 us，一轮 2.8 ms（约 357 Hz）。不占用 BSRAM、无通用乘法器。
- 每轮扫描锁存完整显示值，避免十位、个位混用两次更新。

连接：板载 U24/U25 74HC595，MSB 优先发送 `{DP, g,f,e,d,c,b,a, sel[7:0]}`。
段选及 DP 低有效、位选高有效。DP 输出 1 关闭。

| 信号 | 管脚 | 含义 |
|---|---|---|
| seg7_dio | M18 | 串行数据 |
| seg7_rclk | C2 | 存储锁存时钟 |
| seg7_sclk | F4 | 移位时钟 |

引脚与协议核对来源：本机板厂资料的通用管脚分配表、第 13 章数码管教程。
已接入 RGB / RGB+HDMI 两个顶层及对应 CST、CLI 与 GPRJ，IDE hierarchy 可识别。
验证用 `sim/tb_seg8_status.sv`，包括 PCM 数值扫描、负满幅、窗口末样本、
丢失 sample_tick、十进制转换、串行帧和整轮快照。
`sim/tb_seg8_realtime.sv` 使用默认生产参数，通过实际 HC595 引脚解码，核对
40 ms 峰值窗口、50 kHz 移位时钟、`L 50P 32` 和静音后的 `L 00P 00`。
实机亮度、左右方向仍需烧录观察。
