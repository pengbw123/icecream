# 琶音器第一版

## 使用

- 入口：SETUP 左上方 **ARPEGGIATOR >**，内部页面编号 10。
- 上电默认 OFF；参数默认 120 BPM、1/8、UP、1 个八度、GATE 70%、输入力度、SWING 50%。
- ON 后按住和弦，逐音演奏；第一颗键立即启动。其他键陆续加入，从后续步骤参与。
- OFF 时 MIDI 直通。开关切换先释放踏板和已有声音，等待新的按键开始。
- HOLD 保留松手后的和弦。全部松开后按新和弦，替换旧集合；保持按键时继续增加音。
- STOP 清除和弦并停音，保留开关和 HOLD 设置，再按新键可重新开始。
- 琶音器开启时 CC64 踏板保持选音集合，踏板信息不送给 FM 声部延音。
  踏板松开、且 HOLD 关闭后，仅保留实际仍按住的音。
- 离开 ARP 页面仍可运行，PLAY 页显示 ARP ON；回 FX 调效果器不停止外部键盘/HOLD 演奏。
  页面切换会释放本页触屏按键，和当前菜单的触屏释放规则一致。
- 底部保留 800×128 触屏琴键。VIEW 的 OCT ± 只改变触屏键盘音域，OCTAVES 改变琶音展开。

| 参数 | 范围 |
| --- | --- |
| BPM | 30～240，支持按住 ± 重复调节 |
| RATE | 1/4、1/8、1/16、1/32、1/8 T、1/16 T |
| ORDER | UP、DOWN、UP / DOWN、AS PLAYED、RANDOM |
| OCTAVES | 1～4，只向上展开 |
| GATE | 10%～95%，分别相对当前长/短步骤 |
| VELOCITY | 点数值切换 INPUT / FIXED；± 设置固定值 1～127 |
| SWING | 50%～75%，相邻两步按该比例分配时长，适用于当前所选 RATE |

往返不重复两端音。随机允许连续选择同一音，但每步均有独立起音与松键。
修改节拍/顺序/八度在下一步使用新参数；不切断正在演奏的步骤。
改和弦时尽量保留当前序列位置，重新启动从第一步开始。
按键集合按音高合并，与现有 FM 声部分配一致，不按 MIDI 通道建立独立声部。
最多保存 128 个不同输入音高及其力度；八度展开超出 MIDI 127 的候选音跳过，不截位回绕。
输入跨多个八度时，展开以“原始集合一轮，再下一组八度”的顺序进行；重合展开音仍各占一步。

## 滑音与辅助演奏

- 开启 ARP 时保存并关闭 GLIDE MONO，关闭 ARP 后恢复。ARP 运行时拦截 CC22 开启请求。
- SETUP 主动打开 GLIDE MONO 时退出 ARP，明确开启单音滑音。
- 进入 PRACTICE 时硬件暂停 ARP、清除和弦，练习/示范事件直接进入合成器。
- 退出 PRACTICE 后保留 ARP 开关，但等待新按键，避免旧和弦突然重新播放。
- 音色、FX、主音量继续沿用当前设置。ARP 参数暂存 RAM，上电恢复默认值。
- 音序器播放/录入会退出 ARP；重新开启 ARP 会先停止音序器。两者共享 BPM，RATE/GATE/SWING 各自设置。

## RTL 与接口

`src/midi_arpeggiator.v` 位于 `top.v` 的三个 MIDI 来源合流后、音符所有权队列前。
原始入口监视事件保持给练习判定与按键显示；生成音符进入合成器，内部 bit30 标记 ARP。
已有 bit31 示范事件直通，不会反复被拆成琶音。

节拍/音长用 50 MHz 域的微秒计数执行，软核只计算参数、绘制字符、写寄存器。
候选音分多周期扫描，避免组合排序和除法。扫描与事件队列造成微秒级调度开销；
输出阻塞时保持整个事件及力度不变，并暂停计时，不跳过 Note Off。
两个 128×7 小表用于输入力度和按键顺序，不引入新的厂商 IP、DDR 或帧缓冲。

### UI 总线 `0x23000000` 的 32 位字索引

| 索引 | 功能 |
| --- | --- |
| 36 | 写控制并原子提交 37～40 的四个时长；读已提交控制 |
| 37 | 偶数步时长，微秒，影子寄存器 |
| 38 | 奇数步时长，微秒，影子寄存器 |
| 39 | 偶数步音长，微秒，影子寄存器 |
| 40 | 奇数步音长，微秒，影子寄存器 |
| 41 | 状态，只读 |
| 42～45 | 输入和弦的 128 位音高集合，低字在前，只读 |

控制位：bit0 开关、bit1 HOLD、bit2 固定力度、[5:3] 顺序 0～4、
[7:6] 八度数减 1、[14:8] 固定力度、bit15 STOP 翻转位。
状态：bit0 用户开关、bit1 实际启用、bit2 运行、bit3 当前生成音有效、bit4 踏板，
[15:8] 下一序列位置低 8 位、[23:17] 当前生成音高、[31:24] 输入集合大小。

模块预留 `external_sync`、`sync_step`、`sync_restart`，当前顶层固定内部时钟。
外部传输层后续需把 MIDI Clock 分频到所选步骤，再接入同步接口；本版菜单不开放外同步，
也未增加 USB/蓝牙驱动。同步接口与参数寄存器分离，便于后续音序器或运输层复用。

## 验证入口

- `sim/tb_midi_arpeggiator.sv`：五种顺序、八度与越界、输入/固定力度、音长、HOLD 换和弦、
  踏板、STOP、队列阻塞、练习互斥、关闭直通。
- `sim/tb_touch_ui.sv +arp`：真实 RV32I 固件和 Goodix 引脚模型验证入口、参数、触屏键、
  HOLD/STOP、离开页面继续启用、练习暂停及退出重新等待按键。
- `sim/run_checks.ps1` 已登记新增回归；项目与两份 CLI 构建脚本包含新 RTL，IDE 可展开层次。
- 生成位流后必须运行 `python tools/check_timing.py fm_138k_rgb_hdmi`，不能只以生成 `.fs` 为通过。

实机建议先用 E.PIANO 1、关闭长混响/长延迟，按 C-E-G 核对顺序和音长，再检查踏板、HOLD、
模式切换和音色切换。音效的尾音不等于 MIDI 挂音。
