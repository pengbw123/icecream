# 小音量视觉反馈：显示专用自动增益

波形、延迟 XY 李萨如的幅度现在可以自动放大。默认开启，屏幕右下角
AUTO ON/OFF 按钮切换；开关只影响后续采集的图像，须等下一个快照发布。

- 放大范围为 1、2、4……256 倍，利用移位而非乘法器实现。
- 先完整采集一段原始 PCM，再按这段数据的峰值选倍率并绘图。同一快照内
  倍率恒定；起音突增也不会沿用上一段小音量的高倍率。
- 绘图额外保留 1/8 幅度余量，防止满幅起音贴边；AUTO 关闭也保留此余量。
- XY 的 X/Y 使用相同倍率，历史缓冲存原始 PCM，不改变延迟关系。
- 超出绘图范围的数值饱和处理，不会定点溢出后翻转到另一边。
- 这是归一化观察视图，开启时不能用轨迹大小判断真实音量。电平条和
  削波指示仍读真实 PCM；I2S、音量、音色算法均不受此功能影响。
- 真正的全零信号仍为零，不会凭空画出声音。极低信号的底噪也可能被放大。
- 视觉反馈的采集、峰值跟踪、倍率选择、RAM 写入、像素输出全部是 RTL；
  软核只传递开关状态，不处理音频图形。

实现：`src/audio_wave_scope.v`、`src/audio_xy_scope.v`、`src/rgb_visualizer.v`。
波形用相邻采样点之间的纵向 min/max 跨度绘制，避免复杂波形出现断点。
菜单的固定标签改用 `src/rtl_performance_text.v` 的 8×16 字模；尚未启用的
多页专业菜单没有伪装成已经可用。
UI 状态寄存器 bit31 为“关闭自动增益”，清零即默认开启。

验证包含静音/负满幅/关闭测试、起音峰值、波形连续性、正常/小音量 RGB
光栅测试、真实 UI 固件通过 I2C 触控模型切换 AUTO 的回归。尚须正确 FPC
排线到位后实屏确认。

本次是独立的显示可见性改进，不代表专业多页菜单、效果器与数码管等整体扩展已交付。

`fm_138k_rgb.fs` 生成时间 21:54，主时钟 Fmax 52.782 MHz（要求 50），
像素时钟 Fmax 43.544 MHz（要求 33.333），两时钟 setup/hold TNS 均为 0。
逻辑 17657、寄存器 10401、CLS 13422、BSRAM 116/340、DSP 23.5/298。

一次中间实现发现尚在准备中的字符菜单 RAM 被展开为大量寄存器并造成时序失败。
最终配置 `ENABLE_MENU_TEXT=0`，排除该未完模块后重新完整实现，以上为最终结果。

全参数专业菜单/效果器完成版。
