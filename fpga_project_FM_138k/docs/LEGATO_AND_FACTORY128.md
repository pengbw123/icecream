# 128 原厂音色、力度校准与单音滑音

## 力度

25K `src/top_bridge.v` 的 USB 按键校准上限由 90 改为 80，138K 内部 USB 直连路径的默认上限同步改为 80。
范围 0..80 映射为 MIDI 0..127（Q8 斜率近似，最多约 1 级误差），80 以上限幅为 127。
原始十进制 20 映射为 32；原始 0 保持 Note Off。控制器消息与桥接板原有未校准通道保持原值。
138K 接收桥接 UART 时不做第二次映射。使用 25K 桥接板的实际连接必须同时更新桥接板位流。

## 128 原厂音色

源文件：`D:/a_files/Cartridges/rom1a.syx`、`rom1b.syx`、`rom2a.syx`、`rom2b.syx`。

| 菜单编号 | MIDI 编号 | 音色库 |
|---|---|---|
| 001..032 | 0..31 | ROM1A |
| 033..064 | 32..63 | ROM1B |
| 065..096 | 64..95 | ROM2A |
| 097..128 | 96..127 | ROM2B |

每库全部保留，未去重或挑选。ROM 表继续沿用 `fm_rom1a_*.mem` 历史文件名，但内容已扩为 128 个。
`fm_preset_names.h` 由同一生成器输出，避免软核名称与 RTL 参数表不一致。
7 位预设编号贯穿 MIDI CC27、加载器、监视总线和 UI；PATCH 每页 5 个，26 页，最后一页 3 个。
首页 PREV/NEXT 在 001/128 之间循环，名称和三位编号支持所有四库。

UI[4] 保留原 volume[6:0]、preset[4:0] 在 [11:7]、algorithm[16:12]、voices[21:17]；
预设高两位 preset[6:5] 使用原保留位 [23:22]，固件通过 status_preset() 统一解码。

重新生成：

```powershell
python tools/generators/generate_fm_preset_bank.py D:/a_files/Cartridges/rom1a.syx --extra D:/a_files/Cartridges/rom1b.syx D:/a_files/Cartridges/rom2a.syx D:/a_files/Cartridges/rom2b.syx
```

## 滑音

- SETUP → GLIDE MONO，默认 OFF。ON 时单音、后按键优先；OFF 恢复正常复音。
- CC22 保留原 LATCH 旋钮入口，0 关闭、非 0 开启；值大小不再作为滑音时间。
- 只要存在物理按住的旧键，新按键触发滑音，没有两次按键间隔的门限。
- 物理键历史独立于延音踏板及包络尾音；全部松开后重新按键直接起音，不从尾音滑过去。
- 松开当前最新音符时，回到仍按住的最近一个音符；松开非当前音符不截断当前音。
- 连续换键从当时正在发声的频率继续滑动，保留振荡器相位、算子包络、Pitch EG、反馈与 LFO 状态。
- 固定约 168 ms（最多 8192 个样本），在各算子基础相位增量域做线性滑动并精确收敛到目标；
  固定频率算子保持其固定频率。当前不增加滑音速度或触发间隔菜单。
- 开关模式时结束旧声部并清空按键历史，避免复音残留；换预设、All Notes Off/All Sound Off 也清除历史。
- 滑音参数可通过 0x69 地址 0x00C 回读；SETUP 进入时同步状态。颤音参数与映射本轮未改。
- 顺便修正分配器在最后一个声部为空闲时仍抢占旧声部的问题；分配决策现在包含最后一次扫描结果。

## 验证项目

- `tb_fm_readback`：逐项加载全部 128 个音色，检查编号、全局参数、算子、最后包络及路由表边界。
- `tb_fm_readback +legato`：单音、上/下行、不重置相位/包络、精确终点、回退、延音踏板、All Sound Off 和恢复复音。
- `tb_touch_ui +performance`：真实软核固件，检查首页 128 循环、三位编号/高库名称、最后一页、菜单滑音开关与琴键。
- `tb_velocity80`：使用真实桥接板校准 RTL，遍历 0..127 输入、20→32、端点、单调性、旁路及 CC27 全编号。

实机仍需试听滑音速度与跨音程听感、重叠按键/松键顺序、延音踏板、四库音色和力度手感。
