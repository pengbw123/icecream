下载对应位流后，关闭自动演奏和手势控制，松键等声音消失，METERS清零并确认READY: ONE NOTE，再单按MIDI/触屏琴键。示波器直流耦合、上升沿单次触发，先回首页、等安静、按Single布防，再点琴键；可先设100μs/div、触发约1V，按实际结果调整。脉冲宽度是板内输入接受后到I2S起音帧完成的数字链路时间。慢起音包络会使它变长，250ms超时脉冲不是有效起音数据。

截至11月3日，用户反馈触屏NOTE>I2S=358μs、OK/TIMEOUT=1/0、SKIPPED=0，但P7-15仍未在示波器观察到脉冲；LED0有心跳。冻结网表存在latency_probe输出缓冲，PnR引脚表为D14，尚不能由此认定外部测量已通过。后续需核对接头朝向、P7排针实际位置、探头通道与触发设置，未闭合前保留此限制。

要验证包含DAC的模拟延迟，仍需另一路同时观察模拟音频输出并比较输入标记上升沿与模拟起音。单看这个脉冲不能证明完整键盘到喇叭延迟小于5ms。它也不是手势识别延迟。
