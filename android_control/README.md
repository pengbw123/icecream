## 旧加法固件安装及第一次测试（历史参考）

1. 把 `outputs/Gowin-JDY23-Android-v0.3.4.apk` 传到手机，用系统安装器覆盖安装。按需允许当前文件管理器安装此 APK；本地调试签名，不是应用商店发布版。
2. 在厂家 APP 点断开，退出电脑 BLE 控制器；同一时间只让一个客户端连接 JDY-23。用户烧入匹配当前115200模块的FPGA文件，模块及FPGA正常供电。
3. 打开“高云乐器蓝牙控制”。Android 12 以上授予“附近的设备”；Android 6~11 需位置信息权限和系统定位开关。开关由用户操作，APP 不会强制修改。
4. 点扫描，选择 JDY-23。若扫描没有结果，展开连接页“高级选项”输入模块当前 MAC（已知实物为 `C1:80:10:02:8F:9B`；以后若地址变化，以扫描结果为准）。
5. 等待“可收发 READY”。只有找到 FFE0 服务 / FFE1 特征、成功写入通知 CCCD 后才进入可收发状态。与厂家 APP 只显示 CONNECTED 的链路状态不同。
6. “音色”页点“测试：仅发送延音参数”。“日志”页检查是否出现命令 `0x12`、状态 `0 参数命令已接受`。它只改延音参数，不触发新音符。
7. 单帧通过后再发送完整音色（133 包），编辑 ADSR 或四个锚点的 16 路谐波，然后用你现有演奏输入听变化。上传参数不是触发演奏。

这块蓝色 JDY-23 转接板若标 VCC 3.6~6V，5V是转接板供电范围；不是说 FPGA UART 信号能接5V。蓝牙与 FPGA 共地，TX/RX交叉，核实 UART 逻辑电平。蓝牙RX接FPGA TX，蓝牙TX接FPGA RX。当前实物模块和高速FPGA为115200，源代码默认/旧工程蓝牙串口9600，电脑诊断串口保持115200。

## 协议与可靠性边界

TX 每帧12字节：`A5 5A CMD DATA[8] XOR`，多字节数值小端；XOR为命令与8个数据字节异或。ADSR时间按目前采样率 `48828.125 Hz` 换算，不擅自改成48kHz。

命令 `10/11/12/13` 为 ADSR，`40/41` 为谐波幅度/衰减，`42`仅为完成标记，不是原子提交。

RX每帧6字节：`A5 5A F0 CMD STATUS XOR`，状态0接受、1命令/参数非法、2校验错误、3帧内超时、4内部译码器超时。旧工程或接线未通可能没有回复。

FFE1有写响应属性时优先带响应写，否则无响应写。默认帧间隔40ms，保护9600波特UART；完整133包最少约5.3秒，实际随GATT回调延长。蓝牙发送进度仅表示本地写出/ATT写操作结束，不是 FPGA 已确认全部参数。回复无序号，收到条数不能证明每包唯一对应；失败/超时停止，不保证参数原子更新，可能已有部分参数生效。

## v0.2.1 上传提速与音量

快速模式默认：仍等待每帧本地完成和FPGA ACK，下一帧仅补足两次发送起点之间30ms的剩余间隔。兼容模式：双完成后额外40ms。不会在ACK之前发下一帧，不改蓝牙模块波特率。上传成功后显示本次实测耗时，可同一首曲子对比两种模式；长曲仍受9600UART和BLE连接间隔限制。

音量版文件为 `fpga_jdy23/release/score_volume_v1/version_A/task2_jdy23_score_volume_25k_a.fs`。用户自行烧录。旧score_v1可使用快速上传，但会拒绝新音量命令。播放或弹键时，在曲谱区找到“总音量”，拖动选择数值，再点“应用总音量”；“静音”和“恢复上次非零音量”分别发送0和上次选择的非零值。这里调整FPGA合成器，手机媒体音量键不控制板上喇叭。

音量使用0x56/D0=0..127，其余为0，转换为原合成器CC20，不修改原音频算法。ACK0只表示音量事件已排队；滑块没有读回功能，默认选择100%不自动写入。混响/延迟已有尾音仍会衰减。完整验收见 `outputs/上传提速与音量_v0.2.1_验收.md`。
