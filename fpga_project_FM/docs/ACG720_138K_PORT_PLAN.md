# ACG720-138K 移植草案（2026-10-16）

本文件依据用户本地的 ACG720-138/60K 通用原理图和 60K/138K 资源对比图；
实际焊接器件、屏幕版本和可用管脚仍须以上板实物核对。先保持 25K 工程可用，
138K 使用独立工程和器件约束，避免替换当前可试听版本。

## 板级事实与移植影响

- 芯片资料标称 GW5AT-138：138240 LUT4、6120 Kb BSRAM、298 个 27x18 DSP。
  不能按这些比例直接外推复音数，仍须完整布局布线测 Fmax。
- 原理图 DDR3 U4 为 MT41K128M16JT-125:K（2 Gbit、x16；名义 256 MiB）。
  屏幕双缓冲、采样库及 GUI 适合放 DDR3；确认实板焊接型号后再确定容量。
- J1 是 40-pin RGB TFT FPC：RGB 数据、PCLK、HSYNC、VSYNC、DE、背光以及
  `TP_SCL/SDA/INT/RST`。适合复用现有 TFT V3.0，但 4.3/5 寸触摸排线线序
  不完全相同，接线前对照实际屏幕版本与 J1 管脚。
- HDMI1/HDMI2、ES8388 音频 Codec、CH340 串口、千兆以太网和 CY7C68013
  USB FX2 都在原理图中。ES8388 需要 I2C 配置和 I2S 时钟；HDMI 图像反馈
  可独立于 TFT 菜单使用。
- **关键差异**：板上 USB-C J5 的 D+/D- 接 CY7C68013 USB 设备芯片，不是
  25K Dock 上的 USB-A Host。不能把当前 USB-MIDI Host RTL 只改引脚就接到 J5。
  独立 MIDI 键盘需要外接带受控 5V VBUS、ESD、匹配电阻/下拉的 USB-A Host
  转接板，用 3.3V GPIO 接 D+/D- 并重新验证 PHY/供电；不要把 J5 的 VBUS
  直接反灌给键盘。另一方案是 USB Host 桥接 MCU，经 UART/SPI 发 MIDI。
  FX2 可留作与电脑高速传 PCM/诊断数据，而不是直接接 USB MIDI 键盘。

## 推荐实施顺序

1. **音频最小闭环**：独立 138K 工程移植 FM 核、预设和 UART；先用现有
   MAX98357 接外部 GPIO，确认 16 复音、同音色数字输出，再迁到板载 ES8388。
   这把器件/时钟问题与 Codec 配置问题分开。
2. **MIDI 输入**：选定 USB-A Host 接法并验证枚举、力度、踏板、8 个旋钮；
   不能假设板载 FX2 自动提供主机能力。此阶段保留上位机 UART 演奏作对照。
3. **算子精度与容量**：保留 6 算子/32 算法，先将 16 提至 32 复音，再依
   布线结果评估 48/64；完成 AMS、正弦小数插值、反馈差分及固定频率弯音。
   合成器与 USB/UI 分时或分时钟域，I2S 样点有稳定的截止时间。
4. **TFT 菜单**：优先评估把现有 USB Host 的 RV32I 扩成统一的控制软核，
   负责触摸 I2C、音色库/参数页、字体和 DDR3 帧缓冲；若固件/UI工作量或
   中断响应使 USB 主机轮询不可靠，再换更完整的软核/总线而非直接加第二核。
   双缓冲/脏矩形减少撕裂。屏幕上显示 32 音色、6 算子算法连接、四段 EG、
   当前键/力度、效果器参数。软核只改双缓冲参数寄存器，不进入音频样点关键路径。
5. **RTL 视觉反馈**：PL 从混合 PCM 支路取样，生成波形、峰值、包络/频谱数据，
   与软核菜单图层叠加到 TFT 或 HDMI。若赛题要求图像反馈由 FPGA 逻辑完成，
   保留这条真正的 RTL 数据/绘制路径；软核只管理界面和布局。
6. **数字差分与效果器**：先用 UART 小段抓样，之后可研究 FX2 FIFO 或以太网
   传完整 PCM 到电脑对比 Dexed；音色核达标后才扩展合唱、延迟、混响与滤波。

## 资源与架构原则

- RGB565 800x480 一帧约 750 KiB；双缓冲约 1.46 MiB，放 DDR3，不挤占片上 BSRAM。
- BSRAM 优先给 EG/正弦/预设及每声部状态；DSP 优先给 FM、AMS 和混音。
- 音频时钟、USB、DDR3/视频分域，跨域用异步 FIFO；音频计算在每个样点周期
  内完成且不等待软核、DDR3或画面刷新。
- 复音数、效果器与 UI 应有可综合的开关和利用率报告；“32 复音可行”是首个
  验证目标，不是未综合之前的保证。
