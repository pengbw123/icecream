# DX7兼容状态与后续清单

本文专门记录尚未完成的参数，避免后续功能迭代时遗忘。当前目标是听感兼容与实时可演奏，并不宣称逐位复刻YM21280/原机DAC。

## 本版已经实现

- 32种经典算法、6算子Ratio/Fixed模式、反馈和Oscillator Key Sync；
- ROM1A整库32音色片上预设，上电装载0号，CC27数值0～31直接选音色；
- 算子四段Rate/Level EG、非线性Level、Rate Scaling、Keyboard Scaling、Velocity Sensitivity；
- 算子EG内部精度提高到Q14，保留qrate低两位的4:5:6:7速度比例，并使用完整4096项对数电平表；
- Pitch EG完整约-48～+47.625半音范围，改为Yamaha对数音高域中的线性步进，不再用接近目标时变慢的一阶逼近；
- 六种LFO波形、PMS、AMS、LFO Key Sync，以及“等待后渐入”的两段Delay；
- 反馈使用前两次算子样值，历史保留接近Dexed Q24样值域的28位精度，再按`9-feedback`移位并转换到FPGA的32位相位域；仍需逐样本差分验证；
- 算子EG按Dexed的64采样块推进，使用48,828.125 Hz对应的Q24采样率乘数预计算每档qrate步长；块内按Dexed的`(gain2-gain1+32)>>6`有符号增量逐点更新增益；
- 本机USB键盘通道0的Note On力度实测仅0x20～0x5E，现标定到1～127；打击垫与UART MIDI力度仍按原值处理。端点和开关为`top.v`的`USB_KEY_VELOCITY_MIN/MAX/CALIBRATE`参数，修改后须重新综合；
- Ratio Detune在Note On按MIDI键位查表修正，Fixed Detune按Dexed的非对称规则编译；
- 第4、6算法的反馈标志与Dexed对齐，只有FB_IN与FB_OUT同时置位的算子更新反馈历史；
- LFO同步起点与单极性幅度调制方向按Dexed修正，并扩展Delay计数避免高Delay档永远无法渐入到满幅度；
- LFO Delay改为Dexed/msfa源码中的两段32位相位增量公式，按64个音频样点更新；
- CC64延音踏板：踩下时Note Off只记录松键，抬起时统一进入第四段释放；
- 14位Pitch Bend、MOD颤音、Chorus和Reverb。

## 后续仍需补齐

1. **AMS精确量化**：已修正单极性LFO形状并在对数Level域运算，但四档深度及Level相关非线性仍是近似。
2. **逐位反馈与溢出规则**：反馈拓扑、双样值历史和样值量化尺度已向Dexed靠拢，但正弦/增益表精度仍有差异，尚未完成实际PCM逐位比对。
3. **Fixed算子的Pitch Bend**：当前固定频率算子忽略Pitch Bend；Dexed仍会对它施加外部弯音/主调音。
5. **Portamento**：接口保留，尚未恢复逐声部滑音状态。
6. **正弦插值**：FPGA使用2048点等效正弦表、无小数地址插值；Dexed正弦查表有小数插值。这对反馈重、金属感强的音色尤为重要。
7. **原机DAC/模拟输出特性**：不模拟DX7量化噪声、DAC非线性和模拟滤波；如需复古听感应作为可关闭的后处理效果加入。

本轮代码通过软件单元测试后，仍须在实体板上与Dexed作同音高、同力度、同音频链路的录音对比；不能仅凭资源和时序通过宣称听感已完全一致。

## 本轮25K验证与试听注意

- `top.v` 默认 `FM_AUDIO_ONLY=1`：保留USB-MIDI、ROM1A预设、串口控制、16复音FM和I2S；旁路合唱、混响、额外输出限幅/峰值表并关闭SPI小屏。此模式用于隔离合成内核的音色差异；效果器旋钮和小屏不会响应，输出电平也可能与先前完整版不同。
- 2026-10-16 基线用 Gowin V1.9.12.03 完整综合、布局布线和生成位流通过：CLS 10201/11520、BSRAM 41/56、DSP 21/28，50 MHz时钟的实际Fmax为50.673 MHz。
- LFO Delay源码移植后重新完整综合、布局布线和生成位流通过：CLS 10247/11520（89%）、BSRAM 41/56（74%）、DSP 20.5/28（74%），Fmax为52.140 MHz。此处Fmax来自工具报告的单次布局布线结果，实板仍需测稳定性。
- 64样点EG/块内增益及USB键盘力度标定后，完整综合、布局布线和位流生成通过：CLS 10427/11520（91%）、BSRAM 47/56（84%）、DSP 21/28（75%），50 MHz约束下Fmax 51.561 MHz。时序裕量比旧版小，实板长时间演奏仍需验证。
- 起音整数取整、反馈样值精度与力度端点参数修正后再次完整生成位流：CLS 10517/11520（92%）、BSRAM 47/56（84%）、DSP 21/28（75%），50 MHz约束下Fmax 51.611 MHz。综合与时序通过不等于声音已验证。
- 包括新增EG/力度算术检查在内共19项软件单元测试通过；尚无板上音频录音、Dexed数字输出的逐样本对比，因此此次修正的听感结论有待实测。

## 差分验证第一阶段

`tools/cli/fm_dx7_diff.py`已能生成固定MIDI测试、审计32种算法路由、
直接编译本地Dexed/msfa的FM核心输出静态增益参考音频，并按起音、按键、
释放分段比较两份PCM WAV。ROM1A的`E.PIANO 1` C4示例在
`tools/fm_validation/examples/rom1a_epiano1_c4/`；完整使用方式见
`tools/fm_validation/README.md`。当前审计结果32/32路由一致。
尚未采集板端数字样点；故不能以本项
结果声称音色逐样本相同。

### 完整 Dexed 单音参考

`tools/cli/fm_dx7_diff.py voice-reference`现可从SYX音色库生成完整单音的
Dexed/msfa参考WAV和32位PCM，覆盖算子EG、Pitch EG、力度/键位缩放、LFO、
算法路由及反馈；验证GUI也有对应入口。参考数据使用独立的等律调音实现，
并按音色Transpose处理演奏音符。注意它仍是**Dexed软件参考**，不是FPGA输出，
也不代表“已完成差分”：目前尚无FPGA内部PCM采集和自动RTL差分。

Dexed EG在每个64样点音频块开始处推进一次包络，并由FM算子核在该块内将
线性增益从前值插到新值。FPGA现按声部各自的64采样块做同样的推进和插值；
EG内部仍是Q14，而Dexed使用Q16，幅度调制的四档深度也仍是近似，因此不能
据此声称逐样本相同。本轮已把反馈历史从18位提高到28位，并按Dexed的
两历史样值之和右移`9-feedback`后转成32位相位调制；但该路径仍建立在FPGA的
Q15正弦、Q16增益表上，与Dexed软件核的查表、量化不完全相同，不能据此声称
逐位一致。

## 资源优先级

25K优先保证USB Host、16复音、6算子和稳定50 MHz。精确算法若显著增加DSP/CLS，应先在Mega60K版完成；25K可以通过构建开关在“兼容精度”和“显示/效果器”之间选择。
