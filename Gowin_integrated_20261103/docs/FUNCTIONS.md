# 当前功能

音源采用六算子FM与32种连接算法，支持32复音、128组预置和LIVE/BACKING双Part。32声部由两Part共用。菜单由RV32固件设置状态，RGB像素由RTL绘制。

演奏输入包含CH376 USB MIDI与触屏琴键。音频支持外部功放和ES8388耳机输出。效果链包含滤波、混响、延迟、失真、合唱与移相。菜单可编辑算子、包络、音色和效果。

首页提供波形、李萨如、频谱及32声部显示。板载数码管显示实际声音电平和复音数。32复音演示逻辑保留。

ARP、SEQ、AI伴奏与AI旋律生成功能保留。SD用户音色存储保留。摄像头采集、灰度手势识别及HDMI预览保留。

手势音色模式下，FIST选择BRASS 1（索引0），PALM选择E.ORGAN 2（索引44），V选择GLOKENSPL（索引85）。横向位置改变LIVE音色亮度，纵向位置改变颤音。切换音色等待LIVE声部和尾音结束。原RHYTHM模式保留。

App支持MIDI曲库、蓝牙曲谱上传、25键灯位校准、固定节奏或等键手弹练习，以及FM参数读写。一键映射记录实体键身份，分别处理同音目标的松键。曲谱容量8192事件。曲谱与运行时灯位随掉电清空，手机保存的校准数据可重新发送。

主要协议为0x53自动播放、0x59灯带指引、0x5A手弹练习、0x57能力查询、0x77校准完成与0x78音色参数。实际帧格式见App及 `pc_control/protocol.py`，FM请求通过菜单CPU统一转换。

JDY TX连接P7-9/E13，JDY RX连接P7-10/E14，灯带数据连接P7-6/A19。全部引脚以 `src/acg720_rgb_hdmi.cst` 为准。

原P7-15/D14单线延迟区间标记保留。双线候选使用P7-27/C18与P7-28/C19，只观察首页触屏单音。双线标记的1 ms脉宽是保持时间。数字标记测量范围和模拟输出端延迟应分别记录。
